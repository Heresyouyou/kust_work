# 计划任务静默规范（2026-10-27）

> 触发背景：桌面「全日频繁弹出空白 cmd 黑窗」，弹一下就关、上面什么都不显示。
> 定位结果是新闻抓取计划任务，一并清掉了同类隐患。本文只写**判据与做法**，细节见
> `memory/2026-10-27.md`。

## 一、为什么会弹

Windows 上一条铁律：

| 启动者 | 子进程（控制台程序）的表现 |
|---|---|
| 有控制台（cmd / 普通 python.exe） | **继承**父控制台，不新开窗口 |
| **没有**控制台（pythonw / GUI 程序 / `CREATE_NO_WINDOW` 的子进程） | **新分配一个可见控制台窗口** |

计划任务 `LogonType=3`（INTERACTIVE_TOKEN，在当前用户登录会话里跑）时：

- 直接跑 `python.exe script.py` → 弹黑窗；
- 直接跑 `*.bat` → 由 cmd.exe 解释，**必然**弹黑窗；
- 直接跑 `pythonw.exe` → **无窗口**（GUI 子系统）。

`capture_output=True` **不能**防弹窗 —— 它只重定向 stdout，不决定控制台。
所以 `.bat` 里即使 `>> log 2>&1` 全重定向，用户仍会看到一个**空白**黑窗。

## 二、怎么判「有没有真的弹窗」

⚠️ **不要用「出现了 conhost.exe」当判据**。`CREATE_NO_WINDOW` 也会给子进程配一个
conhost，但那个控制台是**隐藏**的，窗口根本看不见（第一版采样器据此误报，
把 `history_queue.py` 当成弹窗源）。

唯一可靠判据：

```python
EnumWindows → GetClassNameW == "ConsoleWindowClass"（或 CASCADIA_HOSTING_WINDOW_CLASS）
            → IsWindowVisible(hwnd) == True
            → GetWindowThreadProcessId(hwnd) 反查 pid 与父链
```

现成工具：`D:/ZSK/geokb/tools/watch_console_window.py <秒数>`
（0.15s 一轮，抓「弹出→关闭」全过程，写 `state/_window_hits.log`）。

静态排查（找出所有可能弹窗的 spawn 点）：`D:/ZSK/geokb/scripts/audit_no_window.py`。
判据是 `subprocess.run/Popen` 缺 `creationflags`；剩下不修的是手工诊断脚本与
「本来就要窗口」的 Edge 启动。

## 三、标准做法（三层都要对）

**① 计划任务的 action 用 `pythonw.exe`，不要用 `python.exe`、不要用 `.bat`**

**② 用包装脚本承接**（因为 pythonw 下 `sys.stdout is None`，`print()` 会抛
`OSError(22)`，业务脚本里的 print 会把进程搞崩）：

```python
# run_xxx_silent.py —— 由 pythonw 执行
NO_WIN = 0x08000000 if sys.platform == "win32" else 0

def log(msg):                      # 只能落盘，不能 print
    with open(LOG, "a", encoding="utf-8") as f:
        f.write("[%s] %s\n" % (datetime.now().strftime("%F %T"), msg))

subprocess.run([REAL_PY, REAL_SCRIPT, ...], cwd=BASE,
               capture_output=True, text=True, encoding="utf-8", errors="ignore",
               timeout=..., creationflags=NO_WIN)
```

`CREATE_NO_WINDOW` 给的是**隐藏控制台**，由整条后代链继承 —— 所以包装脚本里那次
spawn 之后，业务脚本再 spawn 自己的子进程也不会弹。

**③ 业务脚本内部每个 `subprocess` 都要带 `creationflags=_NO_WIN`**

缺一个就漏一个窗口。文件顶部统一放：

```python
_NO_WIN = 0x08000000 if os.name == "nt" else 0   # CREATE_NO_WINDOW
```

⚠️ 别用 `DETACHED_PROCESS`：实测它**反而**会给子进程新开控制台（`GetConsoleWindow()`
返回真实句柄），与直觉相反。要「无窗口」就用 `CREATE_NO_WINDOW`。

## 五、改法（只能走 COM）

`schtasks.exe` 被安全策略拉黑，`wscript.exe`/vbs 也被判为 LOLBin 拒绝执行。只用：

```python
import win32com.client
svc = win32com.client.Dispatch("Schedule.Service"); svc.Connect()
t = svc.GetFolder("\\").GetTask(NAME)
d = t.Definition
d.Actions.Clear()
a = d.Actions.Create(0)          # 0 = TASK_ACTION_EXEC
a.Path = PYW
a.Arguments = '"%s"' % WRAPPER
a.WorkingDirectory = CWD
svc.GetFolder("\\").RegisterTaskDefinition(NAME, d, 6, None, None, d.Principal.LogonType)
```

**改前先备份 XML**：`t.Xml` 写到 `state/task_backup/<任务名>_<时间戳>.xml`，
回滚时把 XML 导回去即可。
