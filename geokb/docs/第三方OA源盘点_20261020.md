# 第三方 OA 源全量盘点（2026-10-20）

> 问题：被订阅墙拦住的文献，**同一篇**在别处有没有合法可得的副本？
> 红线：只认 DOI 精确相等；无 DOI 不解析；不做标题近似；下载后再用 PDF 正文复核身份。

## 一、结论先说

| 口径 | 篇数 | 占未归档（4398） |
|---|---:|---:|
| **第三方仓储有副本（可直接下载）** | **572** | **13.0%** |
| 出版社 PDF 直链（可达站点，如 Springer / 地球科学） | 102 | 2.3% |
| 出版社自有 OA，但只有落地页（需回源站，Elsevier 多为硬墙） | 2231 | 50.7% |
| 出版社硬墙（ScienceDirect / OUP / GSW） | 218 | 5.0% |
| **closed —— 第三方也没有任何合法副本** | **1275** | **29.0%** |

一句话：**近三成（1275 篇）是真的没有第三方源**；另有 2231 篇虽被标注 OA，
但副本只挂在出版社自己的站点上（Elsevier 的站点我们拿不到），对外部下载者同样不可得。
**真正能靠第三方源解决的，是 572 + 102 ≈ 674 篇（15.3%）**。

## 二、方法与红线

- 通道：Unpaywall（最权威 OA 判定）+ OpenAlex（机构库/预印本覆盖广）。
  两者都返回 `doi` 字段，**必须与请求 DOI 逐字符相等**才采纳该条记录，
  否则记 `doi_mismatch` 丢弃。无 DOI 的条目（636 篇）**直接不解析**。
- 位置去重后按「是否带直链 PDF / 是否仓储 / 是否有版本信息」打分，取最优一条。
- 抽样下载后，把 PDF 前 3 页正文抽出来，要求**原文 DOI 命中**或**原文标题命中**
  （`scripts/pdf_identity.py`）。不通过即判「不是这篇」，换下一个候选。
- OpenAlex 的 `locations` 里**混有非 OA 落地页**，必须按 `is_oa` 过滤，
  否则会把 closed 误算成有 OA（首轮就踩了：757 篇 closed 被误判成 publisher_oa）。

## 四、副本都躺在哪

| 来源 | 篇数 | 性质 |
|---|---:|---|
| 分散高校/机构库（其余） | 288 | 多为 DSpace/Worktribe 记录页 |
| handle 聚合（`hdl.handle.net`） | 85 | 需二次跳转，部分 403 |
| HAL（法国） | 51 | 直链多，稳定 |
| 澳洲高校库（JCU / UWA 等） | 50 | **直链质量最好** |
| 欧洲高校库（UNIGE / KU / VU 等） | 46 | 混合 |
| GFZ（德国地学中心） | 39 | 直链多 |
| figshare | 13 | 数据集型居多 |

572 篇里 **136 篇是直链 `.pdf`**，另外 436 篇是记录页，需要再跳一层
（已加 `resolve_landing_pdf()`：读 `citation_pdf_url` meta 或第一个 `.pdf` 链接，只跳一次）。

**版本构成要看清**：`submittedVersion` 824 条、`acceptedVersion` 135 条、已出版版仅 71 条。
也就是说拿到的多数是**作者投稿稿/接收稿**，排版与出版社版本不同——
入库时应在 `source` 里标明版本，避免与出版版混淆。

## 五、抽样核验（40 篇仓储副本）

| 结果 | 篇数 |
|---|---:|
| 下载成功且身份核验通过 | 5 |
| **内容不符（拿错文章）** | **0** |
| 落地页解析不出 PDF | 10 |
| 被域名策略跳过（用户未授权） | 8 |
| 网络失败 / 超时 | 7 |
| 403（Cloudflare 挡 curl_cffi） | 8 |

两个关键点：

1. **0 例内容不符** —— 聚合器的 DOI 级关联是准的，风险不在元数据，在可达性。
2. 通过率低是**网络环境**造成的，不是源不可用：`hdl.handle.net`、`gfzpublic.gfz.de`、
   `orca.cardiff.ac.uk`、`figshare.com` 等对 curl_cffi 直接 403；`hal.science` 走本机
   HTTP_PROXY 会 502。已加 `trust_env=False` 绕代理，仍未全通。

## 六、closed 是不是真的 closed

对 1275 篇 closed 抽样 123 篇，用**标题归一化后逐字符相等**（不是相似度）去 OpenAlex
反查同一篇的其它版本（预印本、另一条 DOI）：**命中 0**。

结论：这些文章的其它版本（若有）早被 OpenAlex 合并进同一 work 的 `locations`，
上一轮查询已经覆盖。**再按标题搜不会有增量**，不必反复试。

## 七、由这轮盘点落地的改动

| 文件 | 改动 |
|---|---|
| `geokb/scripts/oa_thirdparty.py`（新建） | `build / collect / reclass / report / verify / probe-closed` 六段式盘点工具 |
| `geokb/scripts/pdf_identity.py`（新建） | PDF 正文 DOI/标题复核器，独立子进程可复用 |
| `PostNews/journal_pdf_oa.py` | ① 修 **Unpaywall 早停 bug**（拿到仓储落地页就 break，OpenAlex 的直链 PDF 永远问不到）；② 加 `resolve_landing_pdf()` 一跳取直链；③ 加 `verify_pdf_identity()` 下载后复核；④ 标题反查 DOI 阈值 0.90→0.95 且只认 `journal-article/posted-content` |
| `PostNews/.workbuddy/journal_pdf_downloader.py` | ① `fetch_one(..., doi=)` 把条目 DOI 作为**身份锚点**传下去；② Elsevier 走 **OA 优先**（其 handler 已证伪为死路），命中即返回，不消耗 antibot 额度 |
| `geokb/scripts/history_queue.py` | 新增 `oa_repo_dois()`：第三方仓储有副本的篇目**排到批次前面**（`--no-prefer-oa` 可关） |
| 五个调用点 | `daily_archive_papers` / `history_queue` / `migrate_feed_to_papers` / `backfill_all_pdfs` / `ingest_external_feeds` 全部改为传 `doi` |

实测（Elsevier 一篇，`10.1016/j.oregeorev.2022.104920`）：
旧逻辑 → `paywalled`（58.6s，空手）；新逻辑 → `ok`，15.4 MB，来源 `oa-first:openalex`，
身份核验 `doi_match`。

## 八、局限与下一步

- **436 篇记录页需要浏览器才能拿到 PDF**（DSpace/Worktribe 普遍 JS 渲染），
  当前一跳解析只能覆盖一部分。若要做，复用 `browser_verify_fetch.py` 的持久化 profile。
- **被拒授权的域名**（`hdl.handle.net`、`gfzpublic.gfz.de`、`urn.kb.se`、`dro.dur.ac.uk`、
  `dx.doi.org`）在核验器里已列入 `SKIP_HOSTS`；要恢复需用户放行。
- 建议节奏：夜间 `history_queue` 先吃 572 篇仓储副本（不碰风控），
  白天不再对 Elsevier 空跑 handler（已由 OA 优先挡掉）。
