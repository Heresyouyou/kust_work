## 0. 边界

只做分给你的那一个 sha：**读 → 写 payload → write → commit(本篇) → evict(本篇) → 回一行回执 → 任务结束**。
**禁**：prep、碰别的篇、删任何文件、改台账、自行跑 `build_facet_index.py`（分面由批次收口统一建）。

> **回执发出后本任务即结束**：不要再读第二篇、不要复述、不要等父代理确认、不要输出状态播报
> （「正在处理」「继续等待」一律不写）。父代理靠你那一行回执推进，多说话只是浪费额度。

## 1. 读原文（深度优先，禁只读摘要）

```bash
$PY scripts/ingest_digest.py <sha12> --body              # 正文（已截掉参考文献）+ L 锚点，首选
$PY scripts/ingest_digest.py <sha12> --slices 1480-1560  # 回看某段，次数不限
$PY scripts/ingest_digest.py <sha12> --full              # 仅当 --body 明显缺正文时
```

- **evidence 行号一律用 `--body` / `--slices` 打印的 L 编号**，不要自己估算。
- 必须读到方法、数据、结果、图表说明；只读摘要即写 = 不合格。
- 读不懂 / PDF 为补充材料（全页数据表无正文）/ 征稿简则 / 书评 / `FOR PEER REVIEW` →
  `$PY scripts/agent_ingest.py skip --sha <sha12> --reason "…"`，然后按 §6 回执（注明 skip）。

## 2. payload（Write 到 `state/agent_ingest_wip/payload-<sha12>.json`，禁 heredoc）

必填：`title title_zh lang tags summary abstract key_content core_methods study_area scenarios methods_zh deposit_type_zh notes kps`

- `lang` 显式写 `zh` 或 `en`；`tags` 非空数组；`kps` 必须存在（可为 `[]`）。
- 中文条目：`*_en` 全部留空，**只 `study_area_en` 写英文**；英文条目反之，`*_en` **从原文抽出，严禁由中文回译**。
- `summary` 中文 200–400 字（<150 直接拒，>400 告警）；英文 `summary` ≤1000 字符且不得整段抄 Abstract。

## 3. kp 规则

每条 8 个字段：`title body type reuse why value evidence tags`（缺 `type/reuse/why/value` 即落 null，不合格）

| 字段 | 取值 |
|---|---|
| `type` | 定量结果｜找矿标志｜成因机制｜参数条件｜方法技术｜时空格架｜区域实例 |
| `reuse` | 解释借鉴｜方法迁移｜类比参照｜标定参照｜本区事实（**每篇 ≤1**） |
| `value` | 0–10，必须拉开差距：9–10 必被引用｜7–8 存档｜5–6 一般｜≤4 局部 |
| `evidence` | **只写 `L<起>-L<止>`**，多条英文逗号；禁括号、章节名、中文注释 |
| `body` | **100–260 字**，含「对象 + 属性 + 数值或条件」，脱离本文仍可读懂；禁「本文研究了…」式元叙述 |

取舍只问一句：**这条换个研究区、换个矿床还用得上吗？** 答不上来就删。**0–8 条，宁缺毋滥**；
「本区事实」（样品/流程/设备参数）最多 1 条，测试流程通常 0 条。一句话一个结论，不要一锅烩。

## 4. 写前红线（违反即硬失败）

1. **禁复用旧 payload**：目录里已有 `payload-<sha>.json` 必须逐字段重写，不得直接 write。
2. **禁裸英文双引号**：payload 文本里的引号一律用中文「」，否则 JSON 解析失败。
3. **数值与原文精确字符串完全一致**：不换算、不四舍五入、不改有效位；原文含内部空格的数字照抄（`0.962 3` 不能写 `0.9623`）。
4. **不得写原文没有的数值**——包括自己归纳的区间、阈值、上下界。想写「一般/通常」就改成不含数字的表述。
5. **圈号 ①–⑧ 不得紧贴数字**（`⑥950` 会被读成 6950 直接 FAIL），用「（6）」或加中文隔开。

## 5. 命令

```bash
cd scripts && $PY agent_ingest.py write --force --sha <sha12> --payload ../state/agent_ingest_wip/payload-<sha12>.json
# 报 FAIL 按错误修 payload 重试，最多 3 次；数值类错误改文案、删掉原文没有的数字，不要改数字

$PY agent_ingest.py commit --sha <sha12> --force     # 不要加 --no-facet
$PY ../scripts/ctx_evict.py evict <sha12>            # 或绝对路径 D:/ZSK/geokb/scripts/ctx_evict.py
```

`commit` 打印批次 `partial` 是正常的（别的子代理还没写完），你只对自己这一篇负责。
commit 若提示 `W6 无 facets` / 「无 facets」**不用处理、不要重跑**——批次收口时统一建。
evict 只移自己这一篇的笔记/payload/全文缓存，不动正式条目与知识点。

