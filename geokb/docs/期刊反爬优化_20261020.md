# 期刊 PDF 爬取优化报告（2026-10-20）

> 目标：当天更新的期刊优先爬取；尝试多种方案通过站点人机验证；限流时改为「爬一篇 → 入库一篇 → 再爬下一篇」。

## 一、方案路线实测矩阵

同一篇文章页，只更换 HTTP 客户端（`logs/antibot_matrix.json`）：

| 客户端 | pubs.geoscienceworld.org | academic.oup.com |
|---|---|---|
| `requests`（原实现） | **403** | **403** |
| `curl_cffi` impersonate=**chrome** | **200 正文页** | **200 正文页** |
| `curl_cffi` chrome124 | 200 | 403 |
| `curl_cffi` edge101 | 200 | 403 |
| `httpx` http2 | 200 | 403 |
| Patchright 浏览器 + 持久化 profile | 挑战可过（26s） | 挑战可过，但 PDF 仍回落 |
| 浏览器导出 `cf_clearance` → 复用 | 文章页可免挑战 | 同左 |

**结论：403 的主因是 TLS 指纹（JA3/JA4）+ HTTP/2 帧序，不是「需要人工点复选框」。**
换客户端即可拿到文章页，无需启动浏览器。

## 二、但换客户端并不等于无限量

`logs/gsw_channel_compare.json`：以 1.2s 固定间隔连发 6 篇 → **4 篇 403**。
`logs/gsw_paced_result.json`：当天多轮探测后，即使 20s 间隔，4 篇仍 3 篇被拦。

**结论：风控按 IP 累计升级。TLS 指纹只解决「单次被拦」，连发照样触发行为风控。**
所以真正的解法是三层限速，而不是继续换伪装：

| 层 | 机制 | 取值 |
|---|---|---|
| 篇间间隔 | `PACE_GAP`（跨进程 `state/antibot_pace.json`） | gsw 60s / oup 90s / elsevier 15s / 中文 3s |
| 每日额度 | `DAILY_MAX`（`state/antibot_quota.json`，跨日清零） | gsw 40 / oup 25 篇/天 |
| 失败退避 | `backoff()` 指数退避 + 抖动，重试 1 次 | 15s 起，上限 120s |

## 三、已证伪的边界（别再重复试）

| 尝试 | 结果 |
|---|---|
| 浏览器带 `cf_clearance` fetch `/article-pdf/` | **仍 403**（订阅墙，非反爬） |
| curl_cffi / httpx 对 ScienceDirect | 一律 403（IP 无订阅权限） |
| OUP 反复重试 | 概率性：首访 200，重复访问升级为挑战 |

## 四、落地改动

| 文件 | 改动 |
|---|---|
| `geokb/scripts/antibot_session.py`（新） | 统一会话工厂（curl_cffi 优先 / 自动降级 requests）；CF cookie 缓存；跨进程节流 `wait_turn()`；日额度 `quota_ok()`；退避 `backoff()` |
| `.workbuddy/journal_pdf_downloader.py` | 12 个 handler 全部走 TLS 指纹通道；`fetch_one` 加额度检查 + 节流 + 风控退避重试；新增 `is_cf_challenge()`；**gsw / elsevier 区分风控 403 与订阅 403** |
| `geokb/scripts/browser_verify_fetch.py` | 挑战通过后导出 `cf_clearance` 给 HTTP 通道复用（每站一次浏览器，其余走 HTTP） |
| `geokb/scripts/daily_archive_papers.py` | 候选按「今 / 近 / 存」优先级排序；`--serial-ingest` 逐篇入库；当日失败补试（只补瞬态失败）；修正增量索引解释器 |
| `geokb/scripts/migrate_feed_to_papers.py` | `--max-minutes` 硬限时；`--today-first` 按 updated 倒序；每篇成功立刻 `index_one()`，取消末尾全量 rebuild |
| `geokb/scripts/history_queue.py` | `today_backlog()` 闸门：当天还有未归档文章时，历史爬取让位 |
| `PostNews/daily_run.py` | 外部订阅②：`--full` → `--limit 40 --max-minutes 50 --today-first` |

## 五、验证数据

- **单轮耗时**：改前 `--days 1` 超过 400s 仍未结束（被 timeout 杀掉）；改后 **76s 完成**。
- **判定准确**：3 篇 elsevier + 1 篇 sciengine 全部正确标为 `paywalled`，
  补试范围自动过滤为 0/4（确定性失败不再重试）。
- **逐篇入库**：条目已存在 → `indexed`（秒级）；不存在 → `queued`
  （写 `state/pending_papers_ingest.jsonl`，低谷窗口补抽取，不在高峰调 LLM）。
- **中文源站回归**：geojournals / sciengine / esf 状态语义正确，无新增 403。
