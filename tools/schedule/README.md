# 本地定时回收（Windows 任务计划程序）

把「本地 PDF 超过 48 小时就搬到 NAS 并删除本地副本」这件事，交给 Windows 自带的
任务计划程序，**不依赖 WorkBuddy、不依赖任何常驻进程或外部调度服务**。
机器只要开着、用户登录着，就会在每天 09:00 与 21:00 各执行一次。

## 一键操作

| 目的 | 双击 |
| --- | --- |
| 安装定时任务 | `install_task.bat` |
| 卸载定时任务 | `uninstall_task.bat` |
| 查看状态 + 最近日志 | `status_task.bat` |
| 手动立刻跑一次回收 | `reap_daily.bat` |

安装后任务名为 **`PostNews-NASReaper`**，也可以在「任务计划程序」里直接搜到。

## 默认行为

- **执行时间**：每天 09:00、21:00（无随机延迟，准点触发）
- **回收阈值**：本地译文存在超过 **48 小时** → 归档到 NAS 后删除本地三版本
- **归档内容**：原文 → `S:\Translator_PDFs\uploads`、中文版 → `translated`、双语版 → `duo`
- **错过补跑**：关机/睡眠错过触发时间，开机后会自动补跑一次
- **正在跑时不重入**：靠运行锁 `data\nas_reaper.run.lock`，锁带 1 小时陈旧保护

## 常用自定义

改执行时间（例：改成 8:00 和 20:00）：

```bat
install_task.bat -Times 08:00,20:00
```

改保留时长（例：本地只留 24 小时）：

```bat
install_task.bat -Hours 24
```

手动跑一次并加参数（`reap_daily.bat` 的参数会原样传给 `nas_reaper.py`）：

```bat
reap_daily.bat --status      :: 只看状态，不动文件
reap_daily.bat --dry-run     :: 预演：会归档，但不删本地
reap_daily.bat --hours 0     :: 无视时间，立即回收全部
```

## 完全静默模式（可选）

默认是「用户登录时运行」，执行瞬间可能闪一下窗口。想要**完全无窗口、不登录也执行**，
用管理员身份运行：

```bat
install_task.bat -RunAlways
```

该模式用 S4U 方式注册，不需要保存密码，但**必须由管理员执行注册**。

## 日志

- 位置：`logs\nas_reaper.log`（项目根目录下）
- 每次运行追加一段带时间戳的记录，超过 2 MB 自动轮转，保留 3 份
  （`nas_reaper.log.1` ~ `.3`）
- 每次运行都会写日志，哪怕一个文件都没回收

## 安全保证

回收脚本在删除本地文件前会逐个校验：NAS 副本存在、且文件大小与本地完全一致，
两条都满足才删本地；校验不过的文件保留在本地并记进日志的「保留原因」。
NAS 不可达时直接跳过，本地文件**一个都不动**。

## 排错

**`status_task.bat` 里看到「上次结果」不是 0**（0 或 0x0 才是成功）：

1. 手动跑 `reap_daily.bat`，看终端报什么错 —— 绝大多数问题在这一步就能复现
2. `0x1` 多为脚本执行失败；`0x41301` 表示任务正在运行；`0x8007010B` 多为路径/参数问题
3. 确认 Python 可用：设置环境变量 `POSTNEWS_PYTHON` 指向 `python.exe` 后重新安装
4. 确认 NAS 盘符 `S:` 已映射（UNC 路径 `\\<nas-host>\<share> 也可自动兜底）

重新注册（改完任何配置后都要重装才生效）：先 `uninstall_task.bat`，再 `install_task.bat`。
