路线鉴定总路线与关键特征总览

白云母为单斜晶系二轴晶负光性矿物。鉴定主线：无色片状、鳞片状沿片理定向排列（部分扭折弯曲）、{001} 一组极完全解理、正低~正中突起（单偏光）→ 平行消光 0°、正延性、鲜艳二级顶部~三级初干涉色（石英楔法 n=2）（正交偏光）→ 二轴晶（−）、2V 中等（黑十字明显分裂）（锥光）。与黑云母的三处对照——无色/褐色、干涉色明亮鲜艳/浑浊掩盖、2V 中等（明显分裂）/2V 很小（微弱分裂）——是本记录的得分主线。

图 A 白云母片状定向排列、扭折弯曲与一组极完全解理（示意）
单凭解理不能区分黑云母与白云母（同构造），须靠颜色+干涉色+2V 三对照；扭折弯曲写进晶形行，体现变质应力背景——是"从认矿物上升到读成因"的加分写法。

（一）单偏光系统 —— 晶形、颜色、突起、解理

表 1 单偏光系统记录（三段式）

晶形操作10× 扫视全片观察片理方向与切面形态。
现象∵目标矿物呈片状、鳞片状，沿片理定向排列；部分鳞片扭折弯曲；细长条状切面与假六边形切面并存。
结论∴片状、鳞片状习性，定向排列（变质片理），扭折为应力变形痕迹——变质岩中白云母典型产状。
颜色与多色性操作单偏光选条状切面转物台 360° 连续观察。
现象∵任意方位均无色透明，无任何颜色变化。
结论∴无色、无多色性——与黑云母（褐色强多色性）的第一区别。
突起与贝克线操作缩小光圈，微升镜筒观察贝克线；结合糙面与边缘宽窄。
现象∵提升镜筒贝克线移向矿物，清楚但不强烈；糙面微显、边缘细窄清楚。
结论∴n＞树胶 → 正突起；程度低~中（Np=1.552 略高于树胶、Ng=1.616 正中）→ 正低~正中突起。
解理操作条状切面观察解理缝方向与密度；假六边形切面对照。
现象∵条状切面见一组细密、平直、贯通的极完全解理缝（平行片长方向）；假六边形切面不见解理缝。
结论∴底面{001}一组极完全解理（与黑云母同构造，单凭解理不能区分两者，须靠颜色+干涉色）。
糙面 · 蚀变 · 包裹体操作单偏光+正交偏光逐颗粒检查。
现象∵颗粒洁净，未见蚀变交代与特征包裹体。
结论∴无蚀变、无特征包裹体，记录"未见"。

（二）正交偏光系统 —— 消光、干涉色、延性、双晶

表 2 正交偏光系统记录（三段式）

消光类型操作正交偏光下转物台，观察消光位与解理缝的关系。
现象∵解理缝平行十字丝任一方向时整体消光；斜交 45° 时最亮。
结论∴平行消光（云母族共性）。
消光角操作消光位读数 a₁，解理缝平行纵十字丝读数 a₂。
现象∵|a₁−a₂|=0°，多颗粒一致。
结论∴消光角 0°。
最高干涉色与级序操作正交偏光逐视域对比取最高干涉色（条状切面）；转 45° 最亮位；插 λ/4 云母试板判断升降；缓慢插入石英楔至灰黑（全补偿点）再缓慢抽出，统计紫红色带出现次数。
现象∵全片最高干涉色为鲜艳的红、绿色（明亮清晰，与黑云母的浑浊暗褐对照鲜明）；插 λ/4 试板后降低（异名半径平行，可直接补偿）；插入石英楔干涉色逐级降低至灰黑；缓慢抽出过程观察到 2 次紫红色带，随后恢复鲜艳红绿色。
结论∴紫红带 n=2 → 级序 = n+1 = 三级内 → 最高干涉色二级顶部~三级初；R≈1100~1290 nm，Δ=R/0.03 mm≈0.036~0.043，与白云母 Δ 一致——"无色+鲜艳二三级干涉色"组合是白云母的身份证。
延性符号操作条状切面延长方向（=解理缝方向）转至一、三象限对角线；插石膏试板。
现象∵干涉色升高、带蓝色调。
结论∴同名升高 → 延长方向为慢光 → 正延性。
双晶操作正交偏光转物台 360° 寻找双晶缝。
现象∵未见双晶缝，消光均匀。
结论∴无双晶（偶见解理扭折带，非双晶）。
图 B 最高干涉色级序测定：石英楔法（紫红带 n=2 → 三级序内）
白云母的级序测定是六大矿物中数据链最完整的一条：λ/4 板判升降（异名可补偿）→ 石英楔补偿至灰黑 → 抽出数紫红带 2 次 → n+1 定级序 → R 反推 Δ 与标准值核对，五步环环相扣。

（三）锥光系统 —— 轴性、光性符号、2V

表 3 锥光系统记录（三段式）

干涉图操作换 40× 物镜、推入勃氏镜；选干涉色最低（一级灰白）的大片状颗粒（≈平行{001}切面，即垂直 Bxa 切面）；转物台 45° 观察黑十字变化。
现象∵0° 位黑十字；转 45° 黑十字明显分裂为两条双曲黑臂，光轴出露点分居两臂凹侧顶点、相距中等（约视域半径之半）；转回 90° 复合为黑十字。
结论∴黑十字明显分裂 → 二轴晶，垂直 Bxa 图；与黑云母（微弱分裂）形成对照。
轴性与光性符号操作保持 45° 位（光轴点连线与试板孔方向 NE-SW 一致）；插入石膏试板；观察凹侧与凸侧内圈颜色变化；拔出复核。
现象∵凹侧（双曲臂之间，Bxa 锐角区）升高变蓝；凸侧（外侧，钝角区）降低变橙黄。
结论∴凹侧沿连线方向振动的是慢光 → Bxo=Ng → Bxa=Np → 二轴晶负光性（−）。
2V（估计）操作45° 位估计两光轴点间距与双曲臂弯曲程度。
现象∵两光轴点相距中等（约视域半径之半）；双曲臂明显弯曲但未近直。
结论∴2V 中等（≈29°~47°）。
图 C 垂直 Bxa 干涉图三步判读：明显分裂 · 二轴晶（−）· 2V 中等
二轴晶光性判读口诀：凹侧看锐角区（Bxa 出露区）。凹侧变蓝=连线方向慢光=Bxo 为 Ng → Bxa=Np → 负光性；凹侧变黄则为正光性（如普通辉石）。黑云母与白云母一个"微弱分裂"、一个"明显分裂"，2V 差异是云母二分的定量依据。
