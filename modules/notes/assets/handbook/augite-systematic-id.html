路线鉴定总路线与关键特征总览

普通辉石为单斜晶系二轴晶正光性矿物，辉长岩中呈短柱状~粒状。鉴定主线：近无色、多色性极弱、短柱状+八边形横切面、{110} 解理 87°/93°、正高突起（单偏光）→ 斜消光 Ng∧c≈42°（消光角测定连测 3 颗）、二级上部干涉色、正延性、{100} 简单双晶（正交偏光）→ 二轴晶（+）、2V 中等——凹侧变黄、凸侧变蓝，与角闪石恰相反（锥光）。与角闪石"六查六不同"是本记录的灵魂。

图 A 普通辉石短柱状晶习、八边形横切面与 87°/93° 解理（示意）
解理夹角与消光角是辉石-角闪石定量分水岭的两把尺子：87°/93° 对 56°/124°、Ng∧c≈42° 对 ≈18°。纤闪石化（次生角闪石沿边缘交代辉石）写明交代方向，是成因佐证而非干扰。

（一）单偏光系统 —— 晶形、颜色、突起、解理

表 1 单偏光系统记录（三段式）

晶形操作10× 扫视全片统计晶习；找干涉色低、轮廓完整的颗粒看横切面。
现象∵目标矿物短柱状~粒状（长宽比 2:1~3:1，较角闪石短粗）；横切面近八边形（近方形轮廓四角被柱面截切）。
结论∴短柱状~粒状、半自形；横切面八边形为单斜辉石{110}柱面截切的典型轮廓。
颜色与多色性操作单偏光选柱面切面转物台 360° 连续观察颜色。
现象∵无色~极淡的黄绿色调，转动载物台深浅变化极微弱、几乎不可辨。
结论∴近无色、多色性极弱或不显——与角闪石（绿色、多色性显著）的第一眼分野。
突起与贝克线操作缩小光圈，选边界平直处微升镜筒观察贝克线；结合糙面与边缘宽窄。
现象∵提升镜筒，边缘亮线明显移向矿物；糙面显著、边缘较宽亮。
结论∴n 明显大于树胶 → 正高突起（普通辉石 n=1.67~1.73）。
解理操作找两组解理缝同时清晰、干涉色较低的横切面；物台两次读数测交角；复测 2 颗。
现象∵两组平直完全解理缝相交，b₂−b₁≈87°（补角 93°，近直角）。
结论∴{110} 两组完全解理交角 87°/93° → 辉石族（排除角闪石 56°/124°）。
糙面 · 蚀变 · 包裹体操作单偏光+正交偏光逐颗粒检查边缘与内部。
现象∵部分颗粒边缘被浅绿色纤维状细小柱状矿物交代（交代边数微米级），核部洁净。
结论∴纤闪石化（次生角闪石交代辉石）——辉石→角闪石的单向蚀变，佐证原矿物为辉石。

（二）正交偏光系统 —— 消光、干涉色、延性、双晶

表 2 正交偏光系统记录（三段式）

消光类型操作正交偏光选干涉色最高、含一组纵向解理缝的柱面切面，转至消光位比较与解理缝方位；另看横切面消光。
现象∵柱面切面消光时解理缝与十字丝明显斜交；横切面在两组解理缝对称于十字丝时消光。
结论∴柱面切面斜消光、横切面对称消光——与角闪石同式，须靠解理角+消光角定量区分。
消光角操作柱面切面转至消光位读数 a₁，再转至解理缝平行纵十字丝读数 a₂，|a₁−a₂| 取 ≤45° 小角；连测 3 颗。
现象∵三颗分别测得 39°、42°、43°。
结论∴Ng∧c≈42°（39°~43°）——落入普通辉石 35°~48° 区间，排除角闪石（12°~25°）：两大单斜暗色矿物的定量分水岭。
最高干涉色与级序操作正交偏光逐视域对比全片目标颗粒取最高干涉色；45° 最亮位插 λ/4 云母试板判升降；石英楔补偿至灰黑后缓慢抽出，数紫红色带。
现象∵最高干涉色鲜艳蓝绿~黄绿；插 λ/4 板后降低（异名，可直接补偿）；石英楔至灰黑，抽出过程观察到 1 次紫红色带。
结论∴紫红带 n=1 → 级序 = n+1 = 二级 → 最高干涉色二级上部；R≈800~950 nm，Δ≈0.027~0.032，与普通辉石一致（同片高于角闪石半级）。
延性符号操作选长柱切面，延长方向转至一、三象限对角线（NE-SW）；插石膏试板。
现象∵干涉色升高、带蓝色调。
结论∴同名升高 → 延长方向以慢光为主 → 正延性（Ng∧c≈42°＜45°，c 轴仍位于 Ng 一侧）。
双晶操作正交偏光转物台 360° 观察相邻单体消光关系。
现象∵部分颗粒见平直双晶缝，两侧单体消光位对称错开、不同时消光。
结论∴{100} 简单双晶（辉石常见）。
图 B 消光角测定：Ng∧c≈42°（三颗粒复测）×× 角闪石对照
消光角记录三要素：切面选择（干涉色最高+一组纵解理缝的柱面切面）、读数方法（消光位 a₁ 与解理缝平行位 a₂ 之差取 ≤45° 小角）、复测（连测 3 颗取区间）——只测一颗或只报单值都是常见失分点。

（三）锥光系统 —— 轴性、光性符号、2V

表 3 锥光系统记录（三段式）

干涉图操作换 40× 物镜准焦，推入勃氏镜；找干涉色最低（近全消光）颗粒；转物台 45°。
现象∵0° 位黑十字；转 45° 分裂为两条双曲黑臂，光轴出露点分居两臂凹侧顶点、相距中等；色圈少而清晰；转回 90° 复合。
结论∴黑十字分裂 → 二轴晶，垂直 Bxa 图。
轴性与光性符号操作保持 45° 位（光轴点连线与试板孔方向 NE-SW 一致）；插石膏试板；观察凹侧（两臂之间）与凸侧内圈升降；拔出复核。
现象∵凹侧降低变黄、凸侧升高变蓝（与角闪石负光性所见恰相反）。
结论∴凹侧沿连线方向振动的是快光 → Bxo=Np → Bxa=Ng → 二轴晶正光性（+）。
2V（估计）操作45° 位估计两光轴点间距与双曲臂弯曲程度。
现象∵两光轴点相距中等（约视域半径之半）；双曲臂弯曲明显但不紧靠。
结论∴2V 中等（约 50°~60°）。
图 C 二轴晶（+）判读：凹侧变黄 · 凸侧变蓝（与角闪石镜像对照）
普通辉石与普通角闪石同为二轴晶、同为中等 2V，唯独光性符号相反——凹凸色变互换。考试若同时给两种暗色矿物，把这对镜像写进结论栏，"六查六不同"即告完整。
