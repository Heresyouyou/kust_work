路线鉴定总路线与三种定向切面的方位

系统鉴定按"定向切面"取样：先在薄片中找到三种特定方位的切面，每种切面只测它所能提供的项目，最后汇总定名。三者的空间关系见下图。

图 A 三种定向切面在黑云母晶体中的方位（示意）
黑云母为单斜晶系假六方片状矿物，c 轴 ⊥ 底面 {001}，光轴面⊥(010)、光轴与底面近垂直。本矿物 2V 很小（0°~25°），两光轴出露点相距极近，⊥OA 切面与 ⊥Bxa 切面在薄片中近于无法区分，步骤一取一级灰白大片状颗粒即可；∥光轴面切面即垂直底面的细长条状切面（同时含 Ng、Np，干涉色最高）。步骤三的"⊥C 切面"依片状矿物惯例改取∥底面切面——柱状矿物的横切面概念对片状矿物并不适用，须在记录中如实说明。

（一）找 ⊥OA 的切面 —— 测轴性、光性符号

表 1 ⊥OA（黑云母为 ⊥Bxa 近似）切面记录（三段式）

寻找切面操作正交偏光下逐视域缓转物台，搜寻 360° 内始终保持全消光或一级灰白的颗粒；云母片状习性下，此类颗粒即干涉色最低的大片状（≈平行{001}）颗粒。
现象∵一颗褐色大片状颗粒全消光~一级灰白；单偏光下其颜色深浅不随转台变化（≈只见 Nm≈Ng 方位）。
结论∴该切面 ⊥ 光轴（2V 很小时 ⊥OA 与 ⊥Bxa 切面近于重合）——光沿光轴传播不发生双折射，故全消光。
1）轴性操作换 40× 物镜准焦，推入聚光镜与勃氏镜，观察该颗粒干涉图；再慢转物台 360° 紧盯黑臂端部。
现象∵0° 位黑十字；转 45° 黑十字分裂极不明显——双曲臂紧紧靠拢，隐约可辨每条黑臂由两条贴近的双曲臂组成，仅端部略有分离迹象；两光轴出露点相距极近、近视域中心。
结论∴黑臂确有分离（非十字四臂同步旋转）→ 二轴晶，2V 很小。切忌误判为一轴晶——2V 小时黑十字貌似一轴晶，慢转物台、盯住端部的一丝分离迹象是唯一判据。
2）光性符号操作保持 45° 位（光轴点连线与试板孔方向 NE-SW 一致）；插入石膏试板；观察双曲臂凹侧（两臂之间，Bxa 锐角区）与凸侧内圈颜色变化；拔出复核。
现象∵凹侧升高变蓝、凸侧降低变黄（双曲臂紧靠时观察两黑臂之间的区域）。
结论∴凹侧（Bxa 区）沿连线方向振动的是慢光 → Bxo=Ng → Bxa=Np → 二轴晶负光性（−）。
附：2V 估计操作45° 位估计两光轴出露点间距与双曲臂分离程度。
现象∵两光轴点相距极近（近视域中心）；双曲臂几乎不分离。
结论∴2V 很小（≈0°~25°）——记录"2V 很小"并注明"黑十字近于一轴晶式"。
图 B 垂直光轴（⊥OA≈⊥Bxa）干涉图三步判读：2V 很小的"微弱分裂"陷阱
观察"微弱分裂"必须慢转物台、仔细盯着黑臂端部：2V 很小的干涉图与一轴晶的差别只在端部的一丝分离迹象。插试板时双曲臂紧靠，判读部位取两黑臂之间（凹侧=Bxa 锐角区）。把"近于一轴晶式"写进记录，既防误判又展示观察深度。

（二）找 ∥光轴面的切面 —— 最高干涉色、Ng/Np 颜色、消光、延性

表 2 ∥光轴面（⊥底面条状）切面记录（三段式）

寻找切面操作正交偏光下全片对比干涉色，取干涉色最高的细长条状颗粒（⊥底面切面）。
现象∵全片最高干涉色集中于细长条状切面；单偏光下该切面颜色随转台剧烈变化。
结论∴该切面 ∥光轴面——同时包含 Ng、Np 两振动方向 → 双折射率最大 → 干涉色最高，且是测完整多色性的唯一切面。
1）最高干涉色操作转 45° 最亮位观察；尝试插 λ/4 云母试板验证级序。
现象∵隐约可见鲜艳的红、蓝、绿干涉色（约三级），但被矿物本身深褐色吸收掩盖，实际观感为暗褐-浑浊橙褐色；转至 Ng 方位（深褐色方位）近于全黑（强吸收压倒干涉色）；λ/4 试板插入后颜色变化同样被掩盖、难以判读。
结论∴最高干涉色可达三级顶部（Δ=0.04~0.08），如实记录"被本身颜色掩盖，λ/4 板法、石英楔法不适用"——强吸收矿物的级序以矿物数据+隐约色序佐证，不硬造数据。
2）Ng、Np 的颜色操作回单偏光，条状切面转物台每 45° 停顿，分别记录平行条长、垂直条长方向平行下偏光时的颜色。
现象∵颜色在深褐色（近不透明）与浅黄色（近无色）之间剧烈切换两次：平行条长深褐，垂直条长浅黄。
结论∴Ng=深褐色（红褐）、Np=浅黄色，多色性极强；吸收性 Ng≫Np（Nm≈深褐待底面切面佐证）。
3）消光类型操作正交偏光下转物台至消光位，比较消光位与{001}解理缝方位。
现象∵解理缝平行十字丝任一方向时，颗粒整体消光；斜交时明亮。
结论∴平行消光——云母族沿{001}解理缝恒平行消光，是区别于角闪石（斜消光）的关键。
4）消光角操作转至消光位读物台读数 a₁；再转至解理缝平行纵十字丝读 a₂；多颗复测。
现象∵|a₁−a₂|=0°，多颗粒一致。
结论∴消光角 0°（平行消光，无斜消光角可报）。
5）延性符号操作选浅黄色方位（Np 方位、吸收弱便于观察）的条状切面，延长方向（=解理缝方向）转至一、三象限对角线（NE–SW）；插石膏试板。
现象∵浅色部位可见干涉色升高、带蓝色调。
结论∴同名升高 → 延长方向为慢光 Ng → 正延性（平行消光 0° 即延长方向=Ng，延性为正）。
图 C ∥光轴面（条状）切面：多色性 · 平行消光 · 延性
多色性必须在含 Ng 与 Np 的条状切面（∥光轴面，干涉色最高者）上测定；平行底面切面只见 Nm≈Ng，测不出完整多色性。延性测定选浅黄（Np）方位——深褐方位强吸收会掩盖试板色变，此为强吸收矿物的操作要领。

（三）∥底面切面（片状矿物对"⊥C 切面"的承接） —— 解理、突起、Nm 颜色

表 3 ∥底面切面记录（三段式；片状矿物无柱状"⊥C 横切面"，以∥底面切面承接题板该步）

切面取舍说明说明黑云母为片状矿物，c 轴⊥底面，薄片中的颗粒多为∥底面或⊥底面切面，不存在柱状矿物的"⊥C 横切面"；题板该步的解理组数/夹角、突起、Nm 颜色，改在平行底面（假六边形）与条状切面上完成。
现象∵假六边形切面轮廓规则、不见解理缝；条状切面见解理缝。
结论∴两类切面配合即可完成本步全部项目，如实注明切面取舍。
1）解理组数与等级操作单偏光 40× 在条状切面观察解理缝的方向与密度；假六边形切面同倍率对照。
现象∵条状切面见一组细密、平直、贯通的解理缝（平行条长方向，"竹席"感）；假六边形切面不见解理缝。
结论∴底面{001}一组极完全解理——解理缝方向=片理方向，与晶形两切面的表现自洽。
2）解理夹角—（一组解理，无夹角可测）。一组解理无从谈夹角，如实记录即为规范作答（对照：角闪石/辉石两组解理分别 56°/124°、87°/93°）。
3）突起等级操作缩小光圈，微升镜筒观察贝克线；结合糙面与边缘宽窄。
现象∵提升镜筒贝克线移向矿物；糙面较显著、边缘较宽亮。
结论∴n＞树胶（1.54）→ 正突起，程度中~高 → 正中~正高突起（黑云母 n=1.57~1.70，深色含铁变种偏高）。
4）Nm 的颜色操作单偏光下观察假六边形（∥底面）切面的颜色及转台变化。
现象∵假六边形切面显深褐色，转台深浅仅微变（该切面法线近 Np、光轴近直立，切面内振动方向为 Ng、Nm，只见 Nm≈Ng 方位的颜色）。
结论∴Nm ≈ 深褐。至此多色性公式完整：Ng=深褐、Nm≈深褐、Np=浅黄；吸收性 Ng≥Nm≫Np（云母族沿底面近全消光型吸收）。
5）消光类型操作正交偏光下转物台观察两类切面的消光。
现象∵条状切面解理缝平行十字丝即整体消光（0°）；假六边形切面近全消光（一级灰白，光轴近直立）。
结论∴平行消光（与步骤二一致，互为印证）；假六边形切面近全消光正是步骤一选取干涉图的切面依据。
附：包裹体操作单偏光+正交偏光逐颗粒检查内部包裹体与蚀变。
现象∵零星细小极高突起包裹体周围带浅绿色放射状晕；个别片边缘被浅绿色细鳞片沿解理交代。
结论∴含锆石包裹体（放射晕为黑云母特征性辅助识别标志）；局部轻度绿泥石化（蚀变矿物单独记录，不计入原生矿物）。
图 D ∥底面切面与条状切面：一组极完全解理 · 无解理夹角 · Nm 颜色
片状矿物对题板"⊥C 切面"的承接写法：以∥底面切面补 Nm 颜色与消光佐证，以条状切面完成解理与突起测定，并在记录中注明切面取舍——"一组解理无夹角可测"写明原因即是规范作答，与角闪石/辉石两组解理夹角（56°/124°、87°/93°）形成对照。
