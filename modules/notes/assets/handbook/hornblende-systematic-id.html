图 A 三种定向切面在角闪石晶体中的方位（示意）
角闪石为单斜晶系长柱状习性，c 轴平行柱长；光轴面 ∥(010)。⊥OA 切面法线为光轴（位于光轴面内）；∥光轴面切面同时包含 Ng、Np，双折射率最大，干涉色最高。

（一）找 ⊥OA 的切面 —— 测轴性、光性符号

表 1 ⊥OA 切面记录（三段式）

寻找切面操作正交偏光下逐视域缓转物台，搜寻 360° 内始终保持全消光的颗粒；严格全消光者难寻时，取一级灰黑（近 ⊥OA）颗粒。
现象∵一颗绿色短柱状颗粒全消光；单偏光下其颜色深浅不随转台变化。
结论∴该切面 ⊥OA——光沿光轴传播不发生双折射，故全消光、无多色性变化。
1）轴性操作换 40× 物镜准焦，推入聚光镜与勃氏镜，观察该颗粒干涉图；再转物台 360° 追踪黑臂行为。
现象∵视域中心一条直黑臂横贯（0° 位沿十字丝方向），臂两侧干涉色低（深灰）；转物台黑臂不消失、随物台弯曲，45° 位弯成明显弧形，弧的凸侧恒指一侧。
结论∴单黑臂且转台弯曲 → 二轴晶。（对照：一轴晶 ⊥OA 图为黑十字，转台时四臂同步旋转、永不分裂；本图无十字、仅单臂弯曲。）
2）光性符号操作转至 45° 位（黑臂弯曲最大），先认准凸侧（指向 Bxa 出露方向）；沿 NE-SW 插入石膏试板（慢光 Ns∥试板长边），观察凸侧近光轴点处内圈颜色变化；拔出复核一次。
现象∵凸侧内圈升高变蓝，凹侧对称降低变黄。
结论∴凸侧沿光轴面迹线振动的光为慢光（同名相加故升高）→ 凸侧（Bxa 方向）沿迹线振动趋于 Bxo → Bxo = Ng → Bxa = Np → 二轴晶负光性（−）。
附：2V 估计操作观察黑臂弯曲程度与色圈疏密。
现象∵黑臂弯曲程度小、近于平直。
结论∴2V 大（约 60°~85°）——2V 越大黑臂越直。
图 B 垂直光轴（⊥OA）干涉图三步判读
凸侧恒指向 Bxa 出露方向（步骤②先认准凸侧再插试板）。石膏试板慢光沿 NE–SW，与弯曲后的光轴面迹线方向一致：凸侧同名相加变蓝说明凸侧沿迹线振动的光是慢光；凸侧（Bxa 方向）沿迹线振动趋于 Bxo，慢光即 Bxo = Ng，故 Bxa = Np，负光性。

（二）找 ∥光轴面的切面 —— 最高干涉色、Ng/Np 颜色、消光、延性

表 2 ∥光轴面切面记录（三段式）

寻找切面操作正交偏光下全片对比干涉色，取最鲜艳的长柱状颗粒。
现象∵全片最高干涉色集中于平行柱长延长的长柱颗粒。
结论∴该切面 ∥光轴面——同时包含 Ng、Np 两振动方向 → 双折射率最大 → 干涉色最高。
1）最高干涉色操作颗粒转至 45° 最亮位；插 λ/4 云母试板（R≈147nm）判断可补偿；缓插石英楔至颗粒灰黑（全补偿点），再缓抽出，数紫红色带出现次数。
现象∵最高干涉色蓝绿~黄绿，叠加上矿物本色偏暗（"绿上加绿"）；抽出过程紫红色带出现 1 次。
结论∴级序 = 1 + 1 = 2 → 最高干涉色二级中部（R≈550~800nm，Δ≈0.018~0.027，与角闪石 Δ=0.015~0.025 相符）。
2）Ng、Np 的颜色操作45° 位插石膏试板辨方向——变蓝 → 柱长方向振动为慢光 Ng；回单偏光，分别把柱长方向、垂直柱长方向转至平行下偏光振动方向，记录颜色。
现象∵柱长方向深绿色，垂直柱长浅黄绿色；转台一周颜色两次最深、两次最浅。
结论∴Ng = 深绿、Np = 浅黄绿，多色性显著（Nm 颜色待 ⊥C 切面补测）。
3）消光类型操作转物台至消光位，比较消光位与柱面纵解理缝方位。
现象∵消光时解理缝与十字丝斜交。
结论∴柱面切面斜消光（单斜晶系特征；消光角见下）。
4）消光角操作消光位读物台读数 a₁；转回解理缝平行竖丝读 a₂；|a₁−a₂| 取 ≤45° 小角；连测 3 颗。
现象∵三颗分别测得 17°、18°、19°。
结论∴Ng∧c = 18°（17°~19°），落于普通角闪石 12°~25° 区间，排除单斜辉石（35°~48°）。
5）延性符号操作柱长方向转至 NE–SW 45° 位（平行试板插入方向），插石膏试板。
现象∵干涉色升高变蓝。
结论∴同名半径相加 → 延长方向振动的是慢光 Ng → 正延性。
图 C ∥光轴面（柱面）切面：多色性 · 消光角 · 延性
多色性须在平行 c 轴的柱面切面（即 ∥光轴面切面，干涉色最高者）上测定——只有该切面能同时见到最深与最浅色。消光角测量三步：①转至消光位读 a₁；②解理缝转至平行竖丝读 a₂；③取小角 |a₁−a₂|。

（三）⊥C 的切面 —— 解理、突起、夹角、Nm 颜色、消光

表 3 ⊥C 横切面记录（三段式）

寻找切面操作找轮廓呈近菱形六边形、干涉色最低（一级灰）、多色性变化不明显的颗粒。
现象∵此类颗粒两组解理缝同时清晰展现。
结论∴该切面 ⊥C（横切面）。
1）解理组数与等级操作单偏光 40× 观察解理缝数量与形态。
现象∵两组细密、平直、连续的平行解理缝。
结论∴{110} 柱面解理两组、完全解理。
2）突起等级操作缩小光圈，微升镜筒观察贝克线移动；结合糙面与边缘宽窄。
现象∵贝克线移向矿物；糙面微显、边缘中等清晰。
结论∴n > 树胶（1.54）→ 正突起；糙面微显 → 正中突起（n≈1.62~1.68）。
3）解理夹角操作第一组解理缝转至平行纵十字丝读物台刻度 b₁；续转至第二组平行读 b₂；复测 2 颗。
现象∵b₂ − b₁ = 56°（补角 124°）。
结论∴解理夹角 56°/124° → 角闪石型解理（排除辉石 87°/93°）。
4）Nm 的颜色操作单偏光下转物台观察横切面颜色及变化。
现象∵横切面显绿色，转台深浅仅微变。
结论∴Nm = 绿。至此多色性公式完整：Ng=深绿、Nm=绿、Np=浅黄绿；吸收性 Ng > Nm > Np。
5）消光类型操作正交偏光下转物台观察横切面消光。
现象∵两组解理缝的锐角/钝角平分线与十字丝方位一致时同时消光。
结论∴横切面对称消光（与柱面斜消光互为印证，均为单斜晶系特征）。
图 D ⊥C 横切面：解理夹角 56°/124° · 对称消光
横切面为近菱形六边形（晶体断面呈细长六边形）。测夹角时两次均以"解理缝平行纵十字丝"读数，锐角 56°、钝角 124° 互为补角——与单斜辉石 87°/93° 近直角形成对照，是角闪石/辉石区分的命脉依据。
