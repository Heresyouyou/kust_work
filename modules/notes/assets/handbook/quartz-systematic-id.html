记录要求（原始题板）：系统测定某矿物的光学性质；记录要求：绘图并加简单说明。（一）找 ⊥OA 的切面——特征：正交镜下全消光（近于⊥OA 为一级灰黑）。测定：1) 轴性 2) 光性符号。（二）找 ∥光轴面的切面——特征：具最高干涉色。测定：1) 最高干涉色 2) Ng、Np 的颜色 3) 消光类型、消光角、延性符号。（三）⊥C 的切面——测定：1) 解理的组数和等级 2) 突起等级 3) 解理夹角 4) Nm 的颜色 5) 消光类型。（四）综合各切面的形态，绘出晶形。（五）综合以上各点写出：1.晶形 2.解理（组数、等级）3.解理夹角 4.多色性和吸收性公式 5.突起等级 6.最高干涉色 7.消光类型 8.消光角 9.延性符号 10.轴性 11.光性符号。

路线鉴定总路线与定向切面的方位（一轴晶：两种切面）

系统鉴定按"定向切面"取样。石英为三方晶系一轴晶矿物，光轴与结晶轴 c 一致——因此题板的三种切面在一轴晶中归结为两种：⊥OA 切面即 ⊥C 横切面（同一切面），另加 ∥光轴（∥c 轴）纵切面；每种切面只测它所能提供的项目，最后汇总定名。两者的空间关系见下图。

图 A 定向切面在石英晶体中的方位（示意）
石英为三方晶系一轴晶矿物，光轴与结晶轴 c（柱长方向）一致：⊥OA 切面即 ⊥C 横切面，同一切面承担步骤一（轴性、光性符号）与步骤三（解理、突起、No 颜色）的全部测定；∥光轴切面为平行 c 轴的纵切面，同时含 Ne、No 两振动方向，双折射率最大、干涉色最高。花岗岩中石英多为他形粒状，两种定向切面须在粒间逐一甄别（波状消光颗粒慎用于定向）。

（一）找 ⊥OA 的切面 —— 一轴晶即 ⊥c 轴切面：测轴性、光性符号

表 1 ⊥OA（=⊥c 轴）切面记录（三段式）

寻找切面操作正交偏光下逐视域缓转物台，搜寻 360° 内始终保持全消光的颗粒；严格全消光者难寻时，取一级灰黑（近 ⊥OA）颗粒。
现象∵一颗无色他形粒状颗粒全消光；单偏光下无色透明，转台颜色无任何变化。
结论∴该切面 ⊥OA（=⊥c 轴）——光沿光轴（c 轴）传播不发生双折射，故全消光、无多色性。
1）轴性操作换 40× 物镜准焦，推入聚光镜与勃氏镜，观察该颗粒干涉图；转物台 360° 追踪黑十字行为。
现象∵视域中心黑十字，交点居中、两臂沿十字丝方向，色圈极少；转物台黑十字四臂同步旋转、始终完整不分裂。
结论∴黑十字不分裂 → 一轴晶（对照：二轴晶转 45° 黑十字分裂为双曲臂，如角闪石；一轴晶永不分裂）。
2）光性符号操作转回 0° 位（黑十字平行十字丝），插入石膏试板（R≈550nm，慢光 NE-SW）；观察一、三象限（NE、SW）与二、四象限内圈颜色变化；拔出试板复核一次。
现象∵一、三象限内圈由灰白升高变蓝，二、四象限降低变黄。
结论∴一、三象限半径方向振动的光与试板慢光同名（皆慢光）→ 半径方向为 Ne 且 Ne＞No → 一轴晶正光性（+）。
附：色圈疏密操作观察黑十字外色圈数量与间距。
现象∵色圈极少，仅隐约一至两圈灰环。
结论∴Δ 很小（≈0.009），与石英一致——色圈疏密是双折射率的直观量度（对照：方解石 Δ 极大、色圈密集如年轮）。
图 B 垂直光轴（⊥OA）干涉图三步判读：黑十字不分裂 · 一轴晶（+）
轴性与光性符号的判据分开记：轴性看"转物台黑十字是否分裂"（一轴晶四臂同步旋转、永不分裂）；光性看"0°位插石膏试板后一、三象限内圈升或降"。石膏试板慢光沿 NE-SW 插入，一、三象限半径方向恰与之平行——同名相加变蓝，即半径方向为慢光 Ne。

（二）找 ∥光轴面的切面 —— 一轴晶即 ∥光轴（∥c 轴）切面：最高干涉色、Ne/No 颜色、消光、延性

表 2 ∥光轴（∥c 轴）切面记录（三段式）

寻找切面操作正交偏光下全片对比干涉色，取最亮的目标颗粒。
现象∵目标颗粒中最高干涉色为一级灰白~淡黄，集中于少数颗粒。
结论∴该切面 ∥光轴（∥c 轴）——同时含 Ne（∥c）、No 两振动方向，双折射率最大（Δ=Ne−No≈0.009）→ 干涉色最高（石英 Δ 小，"最高"也只是灰白~淡黄，须与低切面对比方见差别）。
1）最高干涉色操作转 45° 最亮位插 λ/4 云母试板（R≈147nm）判升降；缓插石英楔至颗粒灰黑（全补偿点），再缓抽出统计紫红色带出现次数。
现象∵一级灰白~淡黄；插 λ/4 试板变深灰（降低，异名可直接补偿）；石英楔补偿至灰黑后缓抽，未观察到紫红色带（n=0），干涉色直接回到一级灰白。
结论∴级序 = n+1 = 一级，最高干涉色一级灰白~淡黄；R≈250~300nm，Δ=R/0.03mm≈0.009，与石英完全一致。
2）Ne（Ng′）、No（Np′）的颜色操作单偏光下分别把柱长方向（c 轴迹线）与垂直柱长方向转至平行下偏光振动方向，记录颜色。
现象∵任意方位均无色透明，转台一周颜色无任何变化。
结论∴Ne=No=无色，无多色性（无色矿物照写"无多色性"以区别于有色矿物；No 颜色在（三）⊥c 切面复核）。
3）消光类型操作正交偏光下转物台，观察消光是整体同步还是分区渐进。
现象∵他形粒状颗粒从一侧向另一侧波状渐进消光（明暗界线扫过晶体）；自形柱面切面在柱棱平行十字丝时整体消光。
结论∴波状消光（应力使光率体畸变，花岗岩中石英极常见）；柱面切面平行消光。
4）消光角操作柱面切面转至消光位读物台读数 a₁；柱棱（c 轴迹线）转至平行纵十字丝读 a₂。
现象∵消光位与柱棱平行位重合，|a₁−a₂|=0°。
结论∴消光角 0°（三方晶系 c 轴=光轴，柱面消光位与 c 轴一致）。
5）延性符号操作他形粒状无一致延长方向，如实注明不可测；选自形柱状颗粒（斑晶/伟晶岩中），延长方向（c 轴）转至一、三象限对角线（NE-SW），插石膏试板。
现象∵一级灰白升高变蓝（二级蓝）。
结论∴同名相加升高 → 延长方向振动的是慢光 → c=Ne=慢光 → 正延性（与一轴（+）自洽）。
图 C ∥光轴（∥c 轴）切面：最高干涉色 · 消光 · 延性
石英楔法四步："λ/4 判升降 → 石英楔补偿至灰黑 → 缓慢抽出 → 数紫红色带次数"——n=0 是低级序矿物的典型情形，同样套用"级序=n+1"，写出"未观察到紫红带"本身就是有效数据。延性测定须换自形柱状颗粒：他形粒状无延长方向，如实注明"不可测"再补测，是规范作答。

（三）⊥C 的切面 —— 与（一）为同一切面（一轴晶 c 轴=光轴）：解理、突起、No 颜色

表 3 ⊥C 横切面记录（三段式；该切面即（一）观察干涉图的切面）

切面同一性说明说明一轴晶光轴 = 结晶轴 c，故 ⊥OA 切面与 ⊥C 横切面为同一切面——（三）不另找切面，就在（一）那个全消光颗粒上完成解理、突起、No（=Nm）颜色与消光的测定；单偏光、正交偏光交替观察即可。
1）解理组数与等级操作单偏光 40× 检查该切面及全片十余个目标颗粒的各切面方向，寻找平直解理缝。
现象∵所有颗粒、所有切面均未见平直成组解理缝，仅偶见不规则裂纹（应力产物）。
结论∴无解理——与一切长石类（两组近 90° 解理）的根本区别，石英第一识别要点。
2）突起等级操作缩小光圈，选矿物-树胶边界平直处，微升镜筒观察边缘亮线移动；配合判断糙面与边缘宽窄。
现象∵提升镜筒，边缘细亮线缓慢移向矿物；表面光滑无糙面、边缘细窄清晰。
结论∴贝克线移向折射率高的一方 → n 略大于树胶（1.54），表面光滑、边缘细窄 → 正低突起（n=1.544~1.553）。
3）解理夹角—（无解理，无夹角可测）。如实记录即为规范作答（对照：方解石 75°/105°、萤石 60°/120°、角闪石 56°/124°、辉石 87°/93°）。
4）Nm（=No）的颜色操作单偏光下转物台观察该横切面颜色及变化。
现象∵横切面无色透明，转台一周深浅纹丝不动。
结论∴No（=Nm）= 无色——一轴晶 ⊥c 切面的光率体切面为圆，任意振动方向皆为 No，故颜色不变。至此多色性公式完整：Ne=No=无色，无多色性。
5）消光类型操作正交偏光下转物台观察该切面明暗。
现象∵转台 360° 始终全消光。
结论∴⊥c 切面全消光——与（一）所据现象一致、互为印证（同一颗粒两用，考试时间减半）。
附：晶面与包裹体操作单偏光+正交偏光逐颗粒检查表面洁净度与内部包裹体。
现象∵颗粒表面干净明亮、无土状混浊；部分颗粒内含细小气液包裹体（点线状成串）。
结论∴表面洁净、不蚀变（对照：长石常高岭土化混浊）——石英抗蚀变的佐证；气液包裹体为原生生长痕迹。
图 D ⊥C（=⊥OA）横切面：无解理 · 正低突起 · No 颜色
"无解理"必须写操作与现象（查过、没见到），不能只写"无"——十余个颗粒各切面方向逐一检查是采信前提。一轴晶 ⊥c 切面的光率体切面为圆（半径=No），故颜色不变、正交全消光，与步骤一在同一颗粒上互为印证。
