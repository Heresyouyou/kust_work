第一部分　晶体光学基础概念

1.1 光与晶体：矿物为什么在偏光下"现形"

自然光在垂直传播方向的平面内任意方向振动；偏振光（偏光）只在一个固定平面内振动。偏光显微镜正是利用下偏光镜把自然光变为固定方向的偏光射入薄片，再用上偏光镜检测矿物对偏光的改造。

双折射（重折射）是镜下鉴定理论的基石：自然光射入非均质体后分解为两束振动方向互相垂直、传播速度（折射率）不同的偏光，二者之间产生光程差 R。正是这两束光的干涉造成了正交偏光下丰富多彩的干涉色。

  • 均质体（等轴晶系矿物与非晶质体，如萤石、石榴石、火山玻璃）：光学性质各方向相同，任何方向折射率只有一个值，不发生双折射。
  • 非均质体（中级、低级晶族矿物）：折射率随方向变化，发生双折射。除光轴方向外，任何方向都有双折射。一轴晶有 1 个光轴，二轴晶有 2 个光轴。

光率体：把"光学性质"变成几何模型

光率体是表示光在晶体中传播时折射率空间分布的立体模型，是全部光性测定（轴性、光性符号、2V）的理论工具。

1.3 单偏光系统：观察项目逐项定义

（1）晶形与自形程度

薄片中看到的是晶体切面，同一晶体不同方向切面形态不同，要多看几个颗粒综合判断。自形程度分三级：自形（晶面完整平直，多为结晶早或能力强的矿物）、半自形、他形（充填于先结晶矿物间隙，如花岗岩中的石英）。

（2）解理

解理在薄片中表现为一组或多组平行的细缝。完全程度分四级：

  • 极完全：解理缝细密平直贯通（云母类，{001}）；
  • 完全：解理缝清晰连续（角闪石、辉石 {110}，长石、萤石）；
  • 中等：解理缝断续可见（橄榄石、磷灰石）；
  • 不完全：仅见断口痕迹（石英无解理，仅见不规则裂纹）。

解理角是鉴定柱状暗色矿物的关键：角闪石两组解理夹角 56°/124°，辉石 87°/93°——这是区分两大矿物族的第一判据。测量时选同时显示两组解理的横切面（柱状矿物的垂直 c 轴切面），转至一组解理缝平行十字丝竖丝读数，再转到另一组平行竖丝，两次读数差即解理角。

（3）颜色、多色性与吸收性

薄片中无色矿物（石英、长石、方解石、白云母）对偏光无吸收；含 Fe²⁺/Fe³⁺/Ti 等色素离子的矿物有色（角闪石绿褐色、黑云母褐色）。多色性是转动物台时非均质体颜色深浅变化的现象，成因是不同振动方向吸收不同。观察方法：单偏光下缓缓转动载物台 360°，记录最深与最浅两种颜色及对应方位，写出多色性公式，如角闪石：

Ng = 深绿色，Nm = 绿色，Np = 浅黄绿色

吸收性公式记录相对深浅，如黑云母 Ng > Np（正吸收）。注意：只有定向切面才能看到最深/最浅两个极端颜色，多看几个颗粒。

（4）突起、糙面与贝克线

矿物边缘与树胶（n≈1.54）折射率之差造成突起感：差值越大，边缘越暗越粗，表面越粗糙（糙面），提升或下降镜筒时边缘出现移动的亮带——贝克线。贝克线法则：提升镜筒，贝克线向折射率高的介质移动（缩小锁光圈可使贝克线更清晰）。据此判断矿物折射率高于还是低于树胶，结合边缘、糙面确定突起等级。

（5）包裹体与次生变化

常见包裹体：石英中的电气石/锆石 halo、磷灰石针状包裹体；常见蚀变：斜长石绢云母化（灰白混浊）、钾长石高岭土化（土褐色）、橄榄石蛇纹石化（网格状绿/黄绿色）、辉石绿泥石化（沿解理）。蚀变可作为野外未蚀变矿物名推断依据，也是岩石成因线索。

第二部分　正交偏光核心理论

2.1 消光与消光位

推入上偏光镜（P⊥A）后，通过矿物的偏光若与上偏光镜振动方向垂直，则没有光通过，矿物变暗，即消光。

  • 全消光：转动载物台 360° 始终黑暗。两种情况——①均质体（等轴晶系、非晶质，如萤石、石榴石、玻璃）；②非均质体垂直光轴的切面（不发生双折射）。
  • 四次消光：非均质体的一般切面转 360°，每隔 90° 消光一次（共 4 次），消光位之间 45° 位置最亮（干涉色最强）。矿物振动方向平行十字丝时即为消光位。

"全消光 ≠ 均质体"！看到全消光颗粒，先判断它是否可能是垂直光轴切面（切面内无解理缝、单偏光下无多色性变化），多找几个颗粒确认。反之，"四次消光"即证明非均质体。

2.2 干涉色与双折射率

非消光位时，矿物内两束偏光（快光 Np′ 与慢光 Ng′）发生干涉，产生的颜色即干涉色。决定干涉色的是光程差 R：

R = (Ng′ − Np′) × d　（d 为薄片厚度，标准 0.03 mm）

R 越大，干涉色级序越高。同一矿物不同切面 Δ 不同，只有垂直光轴以外的"最大双折射率切面"（通常即柱状矿物平行 c 轴切面）才显示最高干涉色。鉴定时必须找干涉色最高的颗粒读数。

干涉色级序的确定方法

  • 边缘色圈法（最常用）：颗粒边缘薄、干涉色低，从边缘向中心色序逐级升高；数边缘到中心出现几条红色条带，红带数 + 1 即级序（每条红带为一级顶界）。
  • 石英楔补偿法（精确测定）：①矿物置于 45° 最亮位；②先插入 λ/4 云母试板判断升降——降低（异名半径平行）即可直接补偿，升高（同名）则将物台转 90° 再操作；③从试板孔缓慢插入石英楔，干涉色逐级降低，至颗粒呈灰黑色（全补偿点，R矿物=R楔）；④从此点缓慢抽出石英楔，统计视域中出现的紫红色带次数 n——级序 = n+1（每出现一次紫红即跨越一级顶界）。例：抽出过程见 2 次紫红 → 三级。同时由补偿点楔上刻度可读出 R，除以薄片厚度 0.03 mm 即双折射率 Δ。
  • 熟记锚点矿物：石英一级灰白、磷灰石一级灰、角闪石二级、白云母二~三级、方解石高级白——考试中用锚点矿物对比邻颗粒干涉色，快速定级。

2.3 补色法则与试板：光性测定的核心工具

两个晶体切面叠置（试板 + 矿物），当两者光率体同名轴（快对快、慢对慢）平行时，总光程差等于两者之和，干涉色升高；异名轴（快对慢）平行时总光程差为两者之差，干涉色降低。这就是补色法则——一切试板判断（光性符号、延性、快慢方向）的总原理。

消光角测量标准步骤（以角闪石柱面切面为例）

  1. 选切面：正交偏光下选一个干涉色最高、具一组清晰解理缝的柱状切面（= 平行 c 轴切面），置于视域中心。
  2. 第一次读数：转动载物台至矿物消光位（全黑），记录游标读数 a。
  3. 第二次读数：同方向继续转动载物台，至解理缝平行目镜十字丝竖丝，记录读数 b。
  4. 计算：消光角 = |a − b|。注意结果必须 ≤45°（大于 45° 说明测的是补角，应换算或换颗粒）。
  5. 换 3~5 个颗粒重复，报出范围与代表值：如角闪石 Ng∧c = 18°（12°~25°）。同时记录转动方向（解理缝从消光位顺时针转多少度到竖丝），用于区分正负延性方位。

横切面（两组解理）测对称消光：消光时解理对角线平行十字丝；只需确认"对称"即可，不测具体角度。

2.5 延性（延长）符号

柱状、针状、片状矿物沿延长方向的振动是慢光（Ng）→正延性（+）；是快光（Np）→负延性（−）。测定：把晶体延长方向转至 45°（与试板孔方向一致），插入石膏试板——

  • 变蓝（升）：延长方向平行试板慢光且同名 → 延长方向为慢光 → 正延性；
  • 变黄（降）：延长方向为快光 → 负延性。

常见正延性：角闪石、辉石、云母（沿解理片方向）、石英柱状切面。常见负延性：电气石、磷灰石（均一轴晶（−）且沿 c 轴延长，c=Ne=快光）、绿泥石部分变种。联动规律：一轴晶柱状矿物沿 c 轴延长时，正光性必正延性、负光性必负延性。磷灰石 vs 电气石外形相近（细柱状、平行消光、负延性），靠颜色与干涉色区分：磷灰石无色、一级灰；电气石褐色/绿色强多色性、二级（常被颜色掩盖）。

2.6 双晶

双晶在正交偏光下表现为相邻单体消光位不同（不同时消光，明暗交替）。记录双晶类型：

  • 简单双晶：两单体，一条双晶缝（角闪石、正长石的卡斯巴双晶）；
  • 聚片双晶：多条平行双晶缝，明暗相间条纹（斜长石钠长石律双晶——鉴定斜长石的标志；方解石聚片双晶纹常平行菱形长对角线）；
  • 格子双晶：两组双晶缝交织成格子（微斜长石，区分钾长石种属的关键）；
  • 复合双晶：卡钠复合双晶（斜长石，卡式+钠式）。

单偏光下双晶缝一般不可见（无折射率差），这是与解理缝的区别；但方解石聚片双晶因双晶面两侧 No/Ne 方位不同，单偏光下可见明暗条纹（结合闪突起）。

第三部分　锥光系统与光性符号测定

3.1 锥光装置与切面选择

锥光观察装置：推入上偏光镜（P⊥A）→ 换用高倍物镜（40×）→ 加入锥光镜（拉索透镜）→ 推入勃氏镜（或拉出勃氏镜、摘下目镜直接看镜筒内干涉图）→ 适当缩小锁光圈。此时视域中出现的是干涉图，而非矿物本身影像。

选颗粒是成败关键——不同干涉图对应不同切面：

  • 干涉色最低（近全消光）的颗粒 → 垂直光轴或近垂直光轴切面 → 一轴晶得"黑十字+色圈"图；二轴晶得单黑臂图；
  • 干涉色中等（明显低于最高干涉色）的颗粒 → 可能是二轴晶垂直 Bxa 切面 → 得"黑十字分裂成双曲臂"图；
  • 干涉色最高的颗粒 → 平行光轴/Bxa 切面 → 瞬变干涉图（一闪图），仅辅助判光性。

3.4 光性符号测定：标准操作与完整推理链

光性测定的总原理只有一条——补色法则（同名升、异名降），先弄清干涉图各部位代表的振动方向，再插入试板判断升降，即可推出光性。不要死背口诀，背原理。

（1）一轴晶 · 垂直光轴图测光性

  1. 认清振动方向：干涉图中，沿半径方向振动的光 = 非常光 Ne′；沿同心圈切线方向振动的光 = 常光 No。这是判断的几何基础。
  2. 插试板：45° 方向试板孔插入石膏试板（慢光 Ns 沿试板长边/NE-SW 向）。黑十字区因矿物 R≈0 显示试板本身的红色（"黑十字变红十字"）。
  3. 看一、三象限（NE、SW 象限，即试板慢光与半径方向平行的象限）内圈颜色：变蓝（升高） → 半径方向（Ne′）是慢光 → Ne > No → 正光性（+）；变黄（降低） → 半径方向是快光 → Ne < No → 负光性（−）。二、四象限颜色与一、三象限互补。
  4. 验证：拔出试板恢复黑十字；再插一次确认读数；Δ 大者（方解石）可看色圈移动——同名象限色圈向内收缩（升），异名象限向外扩张（降），结论一致。

例：方解石垂直光轴图 + 石膏试板 → 一、三象限内圈黄、二、四象限蓝 → 径向快光 → Ne（1.486）< No（1.658）→ 负光性（−）。石英 → 一、三象限蓝 → 正光性（+）。

（2）二轴晶 · 垂直 Bxa 图测光性

  1. 转台到 45° 位：使黑十字分裂至最大（两条双曲臂），此时两光轴出露点连线（光轴面迹线）恰与十字丝成 45°，平行试板孔方向；视域中心为 Bxa 出露点。
  2. 认清振动方向：双曲臂之间（凹侧、含中心的 Bxa 区）内，沿光轴点连线方向振动的光趋于 Bxo，垂直连线方向为 Nm；双曲臂外侧（凸侧、Bxo 区）沿连线方向振动趋于另一主轴（正光性时向 Ng 过渡）。
  3. 插石膏试板（慢光沿连线方向）：凹侧（双曲臂之间）内圈变黄（降低）、凸侧变蓝（升高） → 连线方向（凹侧近心处）为快光 → Bxo = Np → Bxa = Ng → 正光性（+）；凹侧变蓝（升高）、凸侧变黄（降低） → Bxo = Ng → Bxa = Np → 负光性（−）。
  4. 验证：转台回 0°（黑十字恢复）再转 90° 再测一次，象限颜色应轮换互补；结论以两次一致为准。

例：角闪石垂直 Bxa 图 45° 位 → 凹侧蓝、凸侧黄 → Bxa = Np → 负光性（−）。白云母同理为负（−）。

（3）二轴晶 · 垂直光轴图测光性

单黑臂弯曲后（45° 位），凸侧指向 Bxa。插入石膏试板，观察凸侧（Bxa 一侧）近光轴点处内圈颜色，判断该侧沿光轴面迹线方向振动的光的快慢：凸侧降低（黄）→ 该方向趋于快光 Bxo → Bxa 为慢光 Ng → 正光性（+）；凸侧升高（蓝）→ 负光性（−）。凸侧方位随转台而变，务必先认准凸侧再插试板。

考试提示 · 光性符号答题模板

光性符号测定是实操考试必考项，失分点多在：① 颗粒选错（选了干涉色最高的颗粒，得到瞬变图）；② 未转到 45° 就插试板；③ 只报结论不写判断过程。答题模板："××矿垂直光轴切面，黑十字+色圈干涉图，一轴晶；插石膏试板，一、三象限升高变蓝，径向为慢光，Ne>No，光性正（+）"——把振动方向、升降、结论一次写全。

3.5 光轴角 2V 的估计

  • 由双曲臂形态定性判断（垂直 Bxa 图 45° 位）：两双曲臂顶点（光轴点）相距近、臂弯曲强烈 → 2V 小；顶点相距远、臂近乎平直 → 2V 大（2V→90° 时两臂合成宽十字；2V 很大时甚至需在垂直 Bxo 图上测）。
  • 简易定量：记光轴点间距 d 与视域直径 D，粗略 2V ≈ (d / D) × 2 × arcsin(NA)，40× 物镜数值孔径 NA≈0.65 时 arcsin(NA)≈40.5°。考试一般只要求定性报告（大/中/小）。
  • 常见矿物 2V 记忆：白云母 2V=30°~47°（中等，双曲臂明显弯曲）；黑云母 2V≈0°~25°（很小，干涉图近似一轴晶黑十字，易误判）；角闪石 2V≈60°~85°（大）；普通辉石 2V≈50°~60°。

第四部分　镜下鉴定标准操作流程（SOP）

4.1 鉴定总流程

透明矿物薄片鉴定五步流程（每步记录结果填入鉴定记录表，见第七~九部分）：

  1. STEP 0 肉眼 + 低倍扫视：岩石类型预判；圈定待测矿物颗粒。
  2. STEP 1 单偏光（PPL）：晶形 · 解理 · 颜色多色性 · 突起糙面 · 蚀变。
  3. STEP 2 正交偏光（XPL）：消光类型/角 · 干涉色级序 · 延性 · 双晶。
  4. STEP 3 锥光：干涉图 → 轴性 · 光性符号 · 2V。
  5. STEP 4 综合定名：对照光性鉴定表 → 矿物名 + 依据 → 复核。

4.2 开机与检查清单

  1. 对光调焦：低倍物镜（4×/10×），调至视域明亮均匀、图像清晰（从侧面看物镜接近薄片后缓慢上提调焦，防止压碎薄片）。
  2. 中心校正：选视域内一小颗粒移至十字丝交点，转载物台一周——若颗粒画圈偏离，用物镜校正螺丝把圆心调回十字丝交点。
  3. 偏光镜正交检验：推入上偏光镜，无薄片（或均质体处）视域应全黑；若发亮，微调上偏光镜至最暗。
  4. 确认十字丝方向：目镜十字丝应分别平行/垂直下偏光镜振动方向（通常十字丝竖丝 = 南北向）。

4.3 单偏光观察清单（逐项记录）

  • 晶形与自形程度（自形/半自形/他形；柱状/粒状/片状/针状）；
  • 解理：组数、完全程度（极完全/完全/中等/不完全）、解理角（横切面）；
  • 颜色与多色性公式（Ng=…，Nm=…，Np=…）、吸收性公式；
  • 突起等级 + 贝克线验证（提镜筒看移向）；闪突起单独记录；
  • 糙面显著程度；包裹体、蚀变产物。

4.4 正交偏光观察清单（逐项记录）

  • 均质性（全消光/四次消光）；
  • 消光类型（平行/斜/对称/波状）+ 消光角（斜消光时，报 Ng∧c 或 Np′∧(010)）；
  • 最高干涉色级序与颜色（多找颗粒，选最高值）→ 估 Δ；
  • 延性符号（延长方向 45° + 石膏试板）；
  • 双晶类型（简单/聚片/格子/复合）。

4.5 锥光观察清单（逐项记录）

  • 干涉图类型（垂直光轴图/垂直 Bxa 图/瞬变图）；
  • 轴性（一轴晶/二轴晶）+ 依据（黑十字是否分裂）；
  • 光性符号（+ / −）+ 完整判断过程；
  • 2V 定性（小/中/大）或定量估计。

4.6 综合定名与复核

将三项系统记录汇总，对照《透明矿物薄片鉴定表》或第十一部分速查表逐项匹配：先按均质/非均质、轴性分流，再按颜色多色性、突起、解理、干涉色、消光、延性逐级排除。定名结论必须附 3 条以上关键依据（考试按点给分）。定名后回视域复核一遍关键特征，防止张冠李戴。

考试时间分配建议（单矿物鉴定 15 min）

扫视选颗粒 2 min → 单偏光 4 min → 正交偏光 5 min（含消光角、延性测量）→ 锥光 3 min → 填写记录 1 min（边测边记更稳妥）。岩石薄片综合鉴定 30~40 min：先整体扫视定结构，再逐一鉴定主要矿物（先多数矿物、后少数矿物、最后副矿物），估计含量后定名。

第五部分　基础矿物镜下识别详解（考试核心）

每个矿物按统一结构编写：参数卡 → 单偏光 → 正交偏光 → 锥光 → 镜下识别操作步骤 → 易混矿物区分。"操作步骤"一节可直接作为考试答题的动作清单；每种矿物独占一页。

5.1 石英（Quartz）· 一轴晶（+）· 考试高频

表 5-1 石英参数卡

折射率No = 1.544，Ne = 1.553；双折射率 Δ = 0.009（弱）

单偏光观察特征

  • 无色透明，薄片中永远无色（多色性无）；
  • 晶形：侵入岩中他形粒状（充填于长石等先结晶矿物颗粒之间，无规则外形）；斑晶或脉石英中呈自形柱状、六方双锥状；
  • 无解理——只有不规则贝壳状断口痕迹，边缘圆滑干净，这是与长石最直观的区别；
  • 正低突起：边缘细而清晰，提镜筒贝克线向石英侧移动；
  • 可见锆石、电气石、金红石等包裹体，含放射性包裹体时周围出现多色晕（放射晕）。

正交偏光观察特征

  • 最高干涉色一级灰白~一级淡黄（Δ=0.009，所有切面都低）；
  • 平行消光：柱面切面柱棱平行十字丝时消光；
  • 波状消光极常见（受应力岩石中标志性现象）——消光呈云雾状波状扫过晶体，而非整体齐黑；
  • 无双晶；延性正（自形柱状晶体）。

锥光观察特征

  • 选干涉色最低（近全消光）的颗粒：黑十字干涉图，色圈极少或不见（Δ 太小）→ 一轴晶；
  • 插石膏试板：一、三象限升高变蓝 → 径向慢光 → Ne > No → 正光性（+）。

镜下识别操作步骤

  1. 低倍扫视锁定颗粒：正交偏光下找干涉色最暗（灰白）、轮廓圆滑、无解理缝的无色颗粒群（花岗岩中他形充填于长石间）。
  2. 单偏光逐项确认：无色 → 无解理（只断口/裂纹）→ 表面干净光滑 → 正低突起（提镜筒贝克线向矿物移动）。
  3. 正交偏光读级序：转台观察四次消光；最高干涉色一级灰白~淡黄；注意观察波状消光并记录。
  4. 锥光定轴性光性：换 40× 物镜，找全消光颗粒 → 黑十字图（几乎无色圈）→ 一轴晶；插石膏试板，一、三象限变蓝 → 一轴晶（+）。
  5. 定名并写依据：石英。依据链——无色、无解理、正低突起、一级灰白干涉色、波状消光、一轴晶正光性。

  • 高级白干涉色（珍珠白、乳白带珍珠光泽感）——视域里最"亮白"的颗粒，转台时闪动；

  • 选干涉色最低（近全消光）颗粒：黑十字 + 多而密的同心色圈（Δ 大，色圈密集，如树木年轮）→ 一轴晶；
  • 插石膏试板：一、三象限降低变黄（色圈向外扩），二、四象限变蓝 → 径向为快光 → Ne < No → 负光性（−）。

  1. 正交偏光扫视：高级白（珍珠白）干涉色的颗粒一望即知——锁定方解石候选颗粒。
  2. 单偏光验证三连：①无色；②两组完全解理、交角约 75°/105°；③转动载物台看闪突起（高、低突起交替）。
  3. 正交偏光补充：确认高级白 + 对称消光（菱形对角线平行十字丝时消光）+ 聚片双晶纹（平行菱形长对角线）。
  4. 锥光定轴性光性：找近全消光颗粒 → 黑十字 + 密集色圈 → 一轴晶；插石膏试板，一、三象限变黄（异名降低）→ 一轴晶（−）。

  • 多色性显著：转动物台颜色深浅明显变化。多色性公式（绿色变种）：Ng = 深绿色 · Nm = 绿色 · Np = 浅黄绿色，吸收性 Ng > Nm > Np（正吸收）。只有平行 c 轴的柱面切面（干涉色最高）才能同时见到最深与最浅色；

  • 最高干涉色二级中部（二级蓝绿~黄绿；因矿物本身有色，叠加后偏暗、偏脏，"绿上加绿"）；
  • 斜消光：柱面切面消光角 Ng∧c = 12°~25°（典型 ≈18°）——消光位与柱面解理缝斜交；横切面为对称消光（两组解理的锐角/钝角平分线平行十字丝）；
  • 延性正（柱状沿 c 轴延长，Ng 平行延长方向）；
  • 可见简单双晶（双晶缝平行 c 轴，两单体消光位不同）。

锥光观察特征

  • 选干涉色中等偏低（介于最高干涉色与全消光之间）的颗粒 → 垂直 Bxa 图：0° 位黑十字，转 45° 黑十字分裂为两条近于平直的双曲臂（2V 大，光轴点相距远）→ 二轴晶；
  • 45° 位插石膏试板：双曲臂之间（凹侧）升高变蓝、外侧（凸侧）降低变黄 → Bxa = Np → 负光性（−）。

镜下识别操作步骤

  1. 低倍扫视锁定：找绿色（或褐色）长柱状、多色性显著的颗粒群；正交偏光下干涉色二级、偏暗者为目标。
  2. 多色性测定（单偏光）：选干涉色最高的柱面切面（= 平行 c 轴切面）置于十字丝中心，缓转物台 360°，记录最深色（Ng 方位）与最浅色（Np 方位）→ 写出多色性公式 Ng=深绿、Np=浅黄绿，吸收公式 Ng>Nm>Np。
  3. 解理角测定（单偏光）：换找近六边形/菱形横切面（无多色性变化、干涉色低的颗粒），测两组解理缝交角 → 56°/124°，解理完全。
  4. 消光角测定（正交偏光）：回到柱面切面——转至消光位读数 a；再转到解理缝平行竖丝读数 b；Ng∧c = |a−b| ≈ 18°（12°~25°）。测 3 个颗粒取范围。
  5. 延性测定：柱状晶体延长方向转至 45°，插石膏试板 → 变蓝 → 正延性。
  6. 锥光定轴性光性：换 40× 物镜，选干涉色中等偏低颗粒 → 黑十字分裂成双曲臂 → 二轴晶；45° 位插石膏试板，凹侧蓝、凸侧黄 → 二轴晶（−）；双曲臂近直、光轴点相距远 → 2V 大。
  7. 定名并写依据：普通角闪石。依据链——绿色/褐色、多色性显著（Ng=深绿，Np=浅黄绿）、两组完全解理 56°/124°、斜消光 Ng∧c≈18°、二级中部干涉色、正延性、二轴晶负光性、2V 大。

镜下识别操作步骤

  1. 低倍扫视锁定：褐色片状、鳞片状矿物；转物台时颜色深浅剧变（深褐↔浅黄）者即黑云母候选。
  2. 多色性测定（单偏光）：选干涉色最高的条状切面（= 垂直 001、含 Ng/Np 的切面），记录最深/最浅色 → Ng=深褐（红褐）、Np=浅黄；吸收公式 Ng≫Np。
  3. 解理确认：条状切面上见一组极完全解理缝（细密平直）；平行底面切面见假六边形轮廓、无解理缝——两者对照记录。
  4. 消光类型（正交偏光）：转至解理缝平行十字丝 → 消光 → 平行消光；45° 位插石膏试板测延性 → 正延性。

  7. 定名并写依据：黑云母。依据链——褐色、多色性极强（Ng=深褐、Np=浅黄）、一组{001}极完全解理、平行消光、正延性、二轴晶负光性、2V 小、含锆石放射晕。

  3. 正交偏光三连：①确认聚片双晶条带轮流消光；②观察环带结构（有则记录"正环带、核部 An 高"）；③结合突起与消光角大小综合定牌号范围。

6.1 鉴定任务与总思路

6.4 QAPF 分类定名流程

  1. 统计浅色矿物相对比例（目估面积法，主要矿物逐一估含量）：Q = 石英；A = 碱性长石（正长石+微斜长石+条纹长石+An<5 的钠长石）；P = 斜长石（An>5）。按 Q : (A+P) 与 A : (A+P) 归类。
  2. 石英含量定酸度档：Q/(Q+A+P)＞20% → 酸性岩（花岗岩类）；5%~20% → 闪长岩/辉长岩向花岗岩过渡（石英闪长岩、花岗闪长岩按 A:P 细分）；＜5% → 中-基性岩。若出现霞石/白榴石（F 值）且无石英 → 碱性岩（霞石正长岩、响岩等）。
  3. A : P 定岩类（以侵入岩为例，石英＞20% 时）：A≈P → 花岗岩；P 明显＞A → 花岗闪长岩→英云闪长岩；无石英且 A 为主 → 正长岩；P 为主+角闪石 → 闪长岩；P 为主+辉石（An>50 基性斜长石）→ 辉长岩；暗色矿物＞90% → 橄榄岩/辉石岩（超基性岩按暗色矿物命名）。
  4. 按结构套定名体系：显晶质等粒/似斑状结构 → 深成岩名（花岗岩、闪长岩、辉长岩…）；斑状+隐晶/玻璃基质或微晶交织 → 喷出岩名（流纹岩、安山岩、玄武岩…）；浅成岩按结构修饰（斑状花岗岩称"花岗斑岩"、辉绿结构称"辉绿岩"）。
  5. 暗色矿物作形容词：含量 5%~20% 的特征暗色矿物前缀命名，如黑云母花岗岩、角闪闪长岩、橄榄辉长岩。

6.6 火成岩薄片鉴定完整操作步骤

  1. 低倍全视域扫视（4×/10×，先正交偏光再单偏光）：判断结晶程度（全晶质/半晶质/玻璃质）、斑状与否、粒度与主次要矿物概貌——先建立"岩石骨架"印象，预判侵入岩还是喷出岩。
  2. 逐一鉴定斑晶/粗粒矿物（单偏光→正交偏光→锥光，按第四部分 SOP）：从数量最多的矿物开始，再鉴定次要多数矿物，最后鉴定副矿物与蚀变矿物。每个矿物记录标准光性特征。
  3. 鉴定基质：辨明基质矿物（微晶斜长石？辉石？玻璃？）与微晶排列方式（定向交织=交织结构；格架充填=间粒/间隐；平行排列=粗面结构；隐晶=霏细）。
  4. 含量目估（面积法）：逐视域估计各矿物面积百分数，多看几个视域取平均，报整数百分含量（考试允许 ±5% 误差）。
  5. 结构命名：综合结晶程度+自形程度+粒度+特征结构，写出 2~3 个结构术语（如"全晶质半自形粒状结构（花岗结构）"或"斑状结构，基质间隐结构"）。
  6. QAPF 定名：按 6.4 流程定岩石基本名；暗色矿物 5%~20% 者加前缀；结构反映相带（深成/浅成/喷出）者套相应名称体系。
  7. 复核与成因一句话：核对矿物组合与岩石名是否自洽（如"花岗岩中出现橄榄石"必然有错）；可补一句成因（侵入/喷出、酸度、演化）。

双晶操作：正交偏光逐颗粒转物台观察双晶。现象：∵部分颗粒见卡氏双晶——两单体以平直结合面（∥{010}）拼合，转物台两半轮流消光、消光位对称于结合面；其余颗粒无双晶。结论：∴卡氏双晶常见而非必有——找不到双晶不能排除正长石；与斜长石聚片双晶（多条细密平行条带）形态截然不同。

核心术语速释（按考试出现频率排序）

术语定义（名词解释作答版）
双折射（重折率）非均质体中不同方向振动的光波折射率不同，最大与最小主折射率之差（Ne−No 或 Ng−Np），产生双折射；薄片下表现为干涉色，Δ 越大干涉色级序越高。
光率体表示光波在晶体中传播时振动方向与相应折射率关系的立体图形（光性指示体）：均质体为球体；一轴晶为旋转椭球体；二轴晶为三轴椭球体。是解释一切光性现象的核心模型。
光程差 R两束偏光通过薄片后的路程差，R = d·Δ（薄片厚度 × 双折射率）。R 决定干涉色级序；补色法则（同名轴相加 R 增大）是试板测定的理论基础。
干涉色级序正交偏光间因光程差不同而出现的干涉色按 R 递增排列的序列，以 550 nm 为一级，Michel-Lévy 色谱为其标准对照。
消光与消光位正交偏光间矿物变暗的现象。当光率体椭圆切面半径与上下偏光振动方向（十字丝）平行时达到消光位。全消光：任意方向都黑暗（均质体或垂直光轴切面）。
消光角消光位时矿物光率体主轴（Ng 或 Np）与解理缝/晶面棱/双晶缝之间的夹角，是单斜、三斜晶系矿物重要鉴定常数（如角闪石 Ng∧c≈18°，辉石≈40°）。
平行/斜/对称消光消光位时解理缝/晶棱与十字丝平行（0°）为平行消光（云母、磷灰石）；斜交为斜消光（角闪石、辉石）；两组解理交角被十字丝平分（解理缝对称于十字丝）为对称消光（角闪石/辉石横切面、方解石沿解理）。
延性符号长条状矿物延长方向与光率体切面长半径的关系：平行 Ng（或 Ng′）为正延性，平行 Np（或 Np′）为负延性；用试板在 45° 位测定（延长方向变蓝为正延性）。
多色性与吸收性单偏光下转动载物台，矿物颜色深浅/色彩变化的现象称多色性（记录 Ng=…、Nm=…、Np=…）；颜色浓度变化称吸收性（如黑云母 Ng＞Np）。只在有色的非均质体中出现。
突起与闪突起矿物边缘与糙面明暗程度反映其与树胶折射率差别的现象称突起；转动载物台突起等级周期变化者称闪突起（方解石特征：Ne 方向负低、No 方向正中），见于双折射率大的矿物。
贝克线矿物与树胶（或相邻矿物）接触边缘处的细亮线，由折射率差引起光的汇聚/发散。提升镜筒（或缩小光圈）时贝克线移向折射率高的一方，用于比较相邻介质 n 的相对大小。
解理等级与解理角极完全（细密连续直线，如云母{001}）、完全（较粗清晰，如角闪石/辉石两组柱面解理）、不完全（断续）。解理角为横切面上两组解理缝的夹角（角闪石 56°/124°，辉石 87°/93°）。
一轴晶/二轴晶只有一个光轴（光沿此方向传播不发生双折射）的晶体为一轴晶（中级晶族，光率体为旋转椭球）；有两个光轴的为二轴晶（低级晶族，光率体为三轴椭球）。
光性符号一轴晶：Ne＞No 为正（+），Ne＜No 为负（−）；二轴晶：Bxa=Ng 为正（+），Bxa=Np 为负（−）。由干涉图结合试板测定（象限升降法或双曲臂凹凸法）。
光轴角 2V二轴晶两光轴（OA）之间的夹角。垂直 Bxa 干涉图上转 45° 后据双曲臂弯曲程度估计：双曲臂近直 → 2V 大；双曲臂弯曲度大（凹向锐角区）→ 2V 小；近于直角相连 → 2V≈90°。
垂直光轴切面切片法线平行光轴的切面：单偏光无多色性，正交偏光全消光（或双折射率最小），锥光显垂直光轴干涉图。鉴定时用于测轴性与光性。
补色法则两光程差相加（同名半径平行）干涉色级序升高，相减（异名半径平行）级序降低至黑（R=0）的原则。石膏试板（R≈550 nm，一级紫红）与云母试板（R≈147 nm，一级灰）测定光性符号、延性、消光角的理论基础。
双晶同种晶体按一定对称规律连生的现象，正交偏光下相邻双晶单体不同时消光而显现双晶缝。类型：简单双晶（正长石卡斯巴双晶）、聚片双晶（斜长石，钠长石律）、格子双晶（微斜长石）、复合双晶（斜长石卡钠复合律）。用于长石鉴定。
环带结构矿物晶体从核心到边缘成分（如斜长石 An 值）连续变化形成的同心环带，正交偏光下各环带消光位依次错开。指示岩浆快速冷却、成分未达平衡，常见于中基性火山岩斜长石斑晶。
反应边结构早结晶矿物与残余岩浆反应，其边缘被新生矿物包围（如橄榄石边缘的辉石反应边），说明岩浆演化未达平衡，见于基性-超基性岩。
包含结构（嵌晶结构）较大的主晶包裹许多细小的客晶（如单斜辉石包裹浑圆橄榄石颗粒），反映矿物结晶顺序的先后关系。
间粒/间隐/交织结构均为基质微晶结构：间粒——斜长石微晶格架间充填细粒辉石+橄榄石+磁铁矿；间隐——格架间充填玻璃质；交织——斜长石微晶（半）定向交织排列，其间夹暗色微晶。分别为玄武岩、玄武岩、安山岩特征结构。
霏细/球粒结构长英质隐晶质基质的两种形式：霏细——显微镜下也难辨晶粒的霏细集合体；球粒——纤维放射状长英质集合体呈球状（十字消光）。酸性喷出岩（流纹岩）基质特征。
花岗结构全晶质半自形粒状结构，自形程度序列为斜长石＞钾长石＞石英（石英他形充填于先结晶矿物粒间），是酸性深成岩（花岗岩类）的特征结构，反映岩浆缓慢冷却结晶。
辉长结构/辉绿结构辉长结构——基性斜长石与辉石自形程度相近、等粒半自形镶嵌（深成）；辉绿结构——自形板条状斜长石搭成三角形格架、他形辉石充填孔隙（浅成），二者为同成分不同产状的结构对。
