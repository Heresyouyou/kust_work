磷灰石综合鉴定记录（按定向切面组织）

记录要求（原始题板）：系统测定某矿物的光学性质；记录要求：绘图并加简单说明。（一）找 ⊥OA 的切面——特征：正交镜下全消光（近于⊥OA 为一级灰黑）。测定：1) 轴性 2) 光性符号。（二）找 ∥光轴面的切面——特征：具最高干涉色。测定：1) 最高干涉色 2) Ng、Np 的颜色 3) 消光类型、消光角、延性符号。（三）⊥C 的切面——测定：1) 解理的组数和等级 2) 突起等级 3) 解理夹角 4) Nm 的颜色 5) 消光类型。（四）综合各切面的形态，绘出晶形。（五）综合以上各点写出：1.晶形 2.解理（组数、等级）3.解理夹角 4.多色性和吸收性公式 5.突起等级 6.最高干涉色 7.消光类型 8.消光角 9.延性符号 10.轴性 11.光性符号。

路线鉴定总路线与定向切面的方位（一轴晶：两种切面）

系统鉴定按"定向切面"取样。磷灰石为六方晶系一轴晶负光性副矿物，光轴与结晶轴 c（柱长方向）一致——因此题板的三种切面在一轴晶中归结为两种：⊥OA 切面即 ⊥C 横切面（同一切面），另加 ∥光轴（∥c 轴）纵切面；每种切面只测它所能提供的项目，最后汇总定名。副矿物颗粒细小（长 0.1~0.3 mm），10× 扫视锁定后换 40× 高倍照常走完全部步骤。两者的空间关系见下图。

图 A 定向切面在磷灰石晶体中的方位（示意）
磷灰石为六方晶系一轴晶负光性矿物，光轴与结晶轴 c（柱长方向）一致：⊥OA 切面即 ⊥C 横切面（横切面呈正六边形轮廓），同一切面承担步骤一（轴性、光性符号）与步骤三（解理、突起、No 颜色）的全部测定；∥光轴切面为平行 c 轴的纵切面（细长柱状轮廓、两端平直），同时含 Ne、No 两振动方向，双折射率最大、干涉色最高——但磷灰石 Δ 极小（≈0.005~0.008），"最高"也只是全片最低最暗的一级深灰~灰白。副矿物细小不等于可省步骤，换 40× 高倍照常走完全表。

（一）找 ⊥OA 的切面 —— 一轴晶即 ⊥c 轴切面：测轴性、光性符号

表 1 ⊥OA（=⊥c 轴）切面记录（三段式）

寻找切面操作10× 扫视浅色矿物粒间、暗色矿物内部与边缘，锁定细小无色柱晶后换 40×；正交偏光下逐视域缓转物台，搜寻 360° 内始终保持全消光的颗粒（横切面呈正六边形轮廓者最典型）。
现象∵一颗横切面近正六边形轮廓的细小颗粒全消光；单偏光下无色透明，转台颜色无任何变化。
结论∴该切面 ⊥OA（=⊥c 轴）——光沿光轴（c 轴）传播不发生双折射，故全消光、无多色性。
1）轴性操作40× 物镜准焦，推入聚光镜与勃氏镜，观察该颗粒干涉图；转物台 360° 追踪黑十字行为。
现象∵视域中心黑十字，交点居中、两臂沿十字丝方向，色圈极少；转物台 45° 黑十字两臂始终平行十字丝、四臂同步旋转、完整不分裂。
结论∴黑十字不分裂 → 一轴晶（对照：二轴晶转 45° 黑十字分裂为双曲臂，如角闪石；一轴晶永不分裂）。
2）光性符号操作转回 0° 位（黑十字平行十字丝），插入石膏试板（R≈550nm，慢光 NE-SW）；观察一、三象限（NE、SW）与二、四象限内圈颜色变化；拔出试板复核一次。
现象∵一、三象限内圈降低变黄，二、四象限升高变蓝。
结论∴一、三象限半径方向振动的光与试板慢光异名（为快光）→ 半径方向为 Ne 且 Ne＜No → 一轴晶负光性（−）。
附：色圈疏密操作观察黑十字外色圈数量与间距。
现象∵色圈极少，仅隐约灰环。
结论∴Δ 很小（≈0.005~0.008），与磷灰石一致——色圈疏密是双折射率的直观量度（对照：方解石 Δ≈0.172，色圈密集如年轮）。
图 B 垂直光轴（⊥OA）干涉图三步判读：黑十字不分裂 · 一轴晶（−）
轴性与光性符号的判据分开记：轴性看"转物台黑十字是否分裂"（一轴晶四臂同步旋转、永不分裂）；光性看"0°位插石膏试板后一、三象限内圈升或降"。石膏试板慢光沿 NE-SW 插入，一、三象限半径方向恰与之平行——异名相减变黄，即半径方向为快光 Ne，负光性。副矿物颗粒细小，锥光图变小但判据不变。

（二）找 ∥光轴面的切面 —— 一轴晶即 ∥光轴（∥c 轴）切面：最高干涉色、Ne/No 颜色、消光、延性

表 2 ∥光轴（∥c 轴）切面记录（三段式）

寻找切面操作40× 正交偏光下对准柱晶，全片对比干涉色，取最亮的目标柱晶纵切面（细长柱状轮廓、两端平直）。
现象∵柱晶纵切面呈一级深灰~灰白，为全片最低最暗的干涉色，集中于柱晶。
结论∴该切面 ∥光轴（∥c 轴）——同时含 Ne（∥c）、No 两振动方向，双折射率最大（Δ≈0.005~0.008）→ 干涉色最高（磷灰石 Δ 极小，"最高"也只是深灰~灰白，与周围长石、石英对比反而最暗）。
1）最高干涉色操作因级序极低，转 45° 最亮位插石膏试板（R≈550nm）做升降算术验证，观察同一切面两个互相垂直方位的颜色变化。
现象∵柱晶呈一级深灰~灰白；插石膏板：同名方位变蓝（550+R≈二级蓝），异名方位变黄（|550−R|≈一级橙黄）。
结论∴由升降算术反推 R≈150~250 nm → 最高干涉色一级深灰~灰白，Δ≈0.005~0.008——"正中突起+一级灰白"经典反差组合（突起中等而双折射极低）。
2）Ng′（=No）、Np′（=Ne）的颜色操作单偏光下分别把柱长方向（c 轴迹线）与垂直柱长方向转至平行下偏光振动方向，记录颜色。
现象∵任意方位均无色透明，转台一周颜色无任何变化。
结论∴No=Ne=无色，无多色性（负光性磷灰石 Ng′=No、Np′=Ne，两者皆无色；No 颜色在（三）⊥c 切面复核）。
3）消光类型操作选纵切面转物台，消光位与柱棱（延长方向）比对；斜交 45° 时对比亮度。
现象∵消光时柱棱（延长方向）平行十字丝；斜交 45° 时最亮。
结论∴平行消光（六方晶系，c 轴=光轴∥柱棱——柱面消光位与 c 轴一致）。
4）消光角操作消光位读数 a₁ 与柱棱平行纵十字丝读数 a₂ 之差。
现象∵|a₁−a₂|=0°，多颗粒一致。
结论∴消光角 0°（平行消光，无斜消光角可报）。
5）延性符号操作纵切面延长方向（柱长=c 轴迹线）转至一、三象限对角线（NE-SW）；插石膏试板观察升降。
现象∵干涉色降低变黄（一级灰白→一级橙黄）。
结论∴异名相减降低 → 延长方向振动的是快光 → c=Ne=快光 → 负延性——一轴晶负光性的必然推论，"负延性+一轴（−）"为磷灰石指纹组合。
附：双晶操作正交偏光转物台 360° 检查双晶缝。
现象∵未见双晶缝。
结论∴无双晶。
图 C ∥光轴（∥c 轴）切面：最高干涉色（升降算术）· 平行消光 · 负延性
石膏板升降算术（同名 550+R 变蓝 / 异名 |550−R| 变黄）反推 R，是低级序矿物定级的规范写法——比"看颜色报级序"更可靠，判卷即认这个推理链。负延性的因果链（c=Ne=快光）与（一）的负光性判断互为印证，两个"负"字自洽即高分。

（三）⊥C 的切面 —— 与（一）为同一切面（一轴晶 c 轴=光轴）：解理、突起、No 颜色

表 3 ⊥C 横切面记录（三段式；该切面即（一）观察干涉图的切面）

切面同一性说明说明一轴晶光轴 = 结晶轴 c，故 ⊥OA 切面与 ⊥C 横切面为同一切面——（三）不另找切面，就在（一）那个全消光颗粒（横切面正六边形轮廓者）上完成解理、突起、No（=Nm）颜色与消光的测定；单偏光、正交偏光交替观察即可。
1）解理组数与等级操作40× 检查该横切面及纵切面各方向，寻找平直解理缝；纵切面另查平行柱长的细纹性质。
现象∵横切面未见平直解理缝；纵切面偶见平行柱长的极细纵纹（连续平直、贯穿晶体）。
结论∴薄片中无解理（磷灰石{0001}底面等解理极不完全，薄片中不显现）；纵纹为柱面晶面条纹而非解理缝——记录中写明区分依据（晶面条纹只显于晶面、非两组成缝，无双晶式明暗）。
2）解理夹角—（无解理可见，无夹角可测）。如实记录即为规范作答（对照：方解石 75°/105°、萤石 60°/120°、角闪石 56°/124°、辉石 87°/93°）。
3）突起等级操作40× 下对准柱晶，缩小光圈，选矿物-树胶边界平直处，微升镜筒观察边缘亮线移动；配合判断糙面。
现象∵提升镜筒，贝克线清楚移向矿物；糙面微显。
结论∴贝克线移向折射率高的一方 → n＞树胶（1.54）且差距中等 → 正中突起（n=1.63~1.66）——介于石英（正低）与辉石（正高）之间的中间档。
4）Nm（=No）的颜色操作单偏光下转物台观察该横切面颜色及变化。
现象∵横切面无色透明，转台一周深浅纹丝不动。
结论∴No（=Nm）= 无色——一轴晶 ⊥c 切面的光率体切面为圆，任意振动方向皆为 No，故颜色不变。至此多色性公式完整：No=Ne=无色，无多色性。
5）消光类型操作正交偏光下转物台观察该切面明暗。
现象∵转台 360° 始终全消光。
结论∴⊥c 切面全消光——与（一）所据现象一致、互为印证（同一颗粒两用，考试时间减半）；平行消光 0° 的观察在 ∥c 纵切面进行（见（二）3））。
附：包裹体与蚀变操作40× 逐颗粒检查内部与边缘。
现象∵柱晶洁净，偶含微小点状包裹体，未见蚀变。
结论∴无蚀变（磷灰石为最稳定副矿物之一）。
图 D ⊥C（=⊥OA）横切面：正六边形轮廓 · 无解理 · 正中突起 · No 颜色
"无解理"必须写操作与现象（查过、没见到），不能只写"无"；纵切面的柱面纵纹要与解理缝辨析——晶面条纹只显于晶面、不成组、无双晶式明暗，是防混淆的加分记录。副矿物颗粒细小，正中突起的贝克线观察须缩小光圈、40× 高倍下进行。
