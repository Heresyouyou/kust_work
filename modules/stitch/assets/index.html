参数设置

默认 0 = 不羽化，保留真实矿物纹理。 羽化是在重叠区把两张亚像素错位的图做加权平均 → 细节必然发糊， 显微图反而丢失颗粒感。消缝已由「内容边界复制 + 多频带融合」完成， 无需羽化。若确要启用，上限 10px。

匹配前统一缩小源图。只加快特征匹配，结果仍按原图出。 图幅请用右边的「输出图幅」控制。

拼接结果的最长边不会超过这个值，超出则整体等比缩小。 档位越小越快、越省内存、文件越小。选「自动」则按可用内存尽量出大图， 并把结果放回原尺寸网格以保持比例标定；指定档位时按所选的尺寸出图， 不再放大（放大只会插出假像素），等效像素尺度见结果里的「缩放」。 档位按 ~1.25 倍细分（16K→1K），不够用可选「自定义」直接填最长边像素 （1024~65536）；拿不准就选「推荐」，按张数与帧宽自动定档（依据见上一行）。

内置引擎用 SIFT 匹配 + 全局最小二乘优化 + 多频带融合， 是显微图的默认选择。OpenStitching 在本机数据上出现过相机参数退化 （放射状拖影），仅作对比用。
