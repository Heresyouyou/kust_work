# BabelDOC 0.2.33 的 PDFPageInterpreterEx 直接读写解释器上的 self.ncs：
#     babeldoc/pdfinterp.py:  self.ncs = self.csmap[...]   /  if self.ncs:
# 而 pdfminer.six 自 20250506 起做了一次重构，把颜色空间状态从解释器搬到了
#     self.graphicstate.ncs
# 并且 init_state() 里不再初始化 self.ncs（20250416 仍在设 self.ncs = None）。
# 结果：pdfminer>=20250506 + BabelDOC 0.2.33 → 解析 PDF 阶段直接抛
#     AttributeError: 'PDFPageInterpreterEx' object has no attribute 'ncs'
#     任务 status=failed，progress=0（连翻译都没开始）
#
# 实测：20250416 ✅ 可用（解释器上仍有 self.ncs）
#       20250506 / 20251107 / 20251227 / 20251230 / 20260107 ❌ 全部崩
#
# 2026-09-13 22:05 就发生过一次：被升级到 20260107，导致所有翻译任务在
